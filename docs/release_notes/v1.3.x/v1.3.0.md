## [1.3.0] - 2026-06-27

### Overview

v1.3.0 is a layered authorization and architectural remediation release. This version redesigns the L3 Notary into a two-layer model (passkey authorization + mTLS transport authentication), splits the monolithic `outboundL3Notary` into three purpose-specific notary types, separates `PasskeyService` domain logic from HTTP handler concerns, removes dead fields from `L5Actuator`, unifies the dual `SQLAuditStore` in outbound mode, and decomposes `cert.go` for testability. The release also adds comprehensive test coverage for reporting verification, CLI cert enrollment, and the full L3 approval pipeline.

### Added

* **Layered L3 Authorization Model** — Redesigned L3 notary to a two-layer model: passkey authorization (Layer 1, always required in gateway mode) and mTLS transport authentication (Layer 2, additional for CLI callers). `ErrPasskeyProofRequired` is returned when passkey proof is missing, providing a clear error for old CLI binaries. Implemented in `internal/services/governance/l3_notary.go`.
* **L3 Notary Split** — Split the single `outboundL3Notary` struct into three types implementing `L3Notary`: `gatewayNotary` (passkey + optional mTLS), `outboundNotary` (suspended tx + signature only), `cliNotary` (CLI session + shared outbound verification). Shared logic extracted into `verifyOutboundProof` helper. Constructor signatures unchanged.
* **Browser-Based Approval Flow** — Rewrote `approve` command to browser + mTLS polling flow. CLI opens browser to `/api/v1/approve/{txHash}`, browser handles WebAuthn ceremony, CLI polls `GET /api/v1/approvals/status/{txHash}` via mTLS until approved or timeout (5 minutes).
* **PasskeyService / PasskeyHandler Domain-HTTP Split** — `PasskeyService` reduced to domain-only fields (userStore, sessionStore, webauthn, logger, rpID, rpName). New `PasskeyHandler` struct embeds `*PasskeyService` and adds HTTP concerns (webSessionSvc, responder, maxPayload, mcpSvc, suspendedStore). All HTTP handler methods moved to `*PasskeyHandler` receiver. `VerifyL3Proof` remains on `PasskeyService` (L3 binding to transaction hash).
* **Approval Handler Consolidation** — Moved all 6 approval handlers from `AuthController` to `PasskeyHandler` (`passkey_service_approvals.go`). Added `MCPServiceProvider` interface and `SetApprovalDependencies` setter. Removed `mcp` and `suspendedStore` fields from `AuthController`.
* **Passkey WebAuthn Fields on Suspended Transactions** — Added `PasskeyCredentialID`, `PasskeyClientDataJSON`, `PasskeyAuthenticatorData`, and `PasskeySignature` fields to `SuspendedTransaction` model. New `ApprovalProof` struct holds all fields needed to record an L3 approval (both Ed25519 CLI and passkey WebAuthn fields). `ApproveSuspendedTransaction` interface method updated to accept `models.ApprovalProof`.
* **DB Migration for Passkey Columns** — Added `migratePasskeyColumns` to `SuspendedTransactionService` for backward-compatible schema migration of passkey fields on the `suspended_transactions` table.
* **CertPaths Struct** — Introduced `CertPaths` struct in `cert.go` to decouple enrollment and renewal functions from the global `paths.Infra` singleton. `PerformAutomaticEnrollment` now returns the operator session ID instead of setting it via `os.Setenv`.
* **cert.go Decomposition** — Decomposed `RenewOperatorCertificate` into 5 testable units: `checkCertExpiry`, `fetchAndSaveTrustBundle`, `buildMTLSClient`, `submitRenewal`, `saveRenewedCerts`. Added HTTP timeout client and `NewRequestWithContext` in `fetchAndSaveTrustBundle`. Standardized error wrapping with descriptive messages.
* **Tribunal and Reputation Event Constants** — Added 21 new event constants for AI tribunal session lifecycle, voting rounds, consensus, and audit events. Added `EventAiReputationStateUpdated`, `EventAppCaseDeleted`, `EventAppInvestigationDeleted`, `EventAppMemoryCreated`, `EventAppMemoryUpdated`, and `EventOperatorPortCheckRequested`.
* **Protocol Status Constants** — Added `ComponentStatus`, `WorkflowType`, and `AITaskId` typed string constants. Added `VersionStabilityUnstable` and `VersionStabilityDeprecated` values.
* **Protocol Python Enums** — Added `protocol/python/g8e/enums.py` with Python enum definitions matching Go constants for status, events, and API paths.
* **L3 Approval Pipeline Integration Test** — Added `internal/services/governance/l3_approval_pipeline_integration_test.go` (245 lines) verifying the full CLI to browser to approval to L3 verification pipeline.
* **Reporting Verification Tests** — Added `internal/services/reporting/verification_test.go` (497 lines, 15 tests, 80.8% coverage) covering all 5 verification checks: commitment chain integrity, git merkle root, file mutation linkage, receipt/commitment cross-link, and context cancellation.
* **Reporting Executions Tests** — Added `internal/services/reporting/executions_test.go` (325 lines, 9 tests) for execution reporting.
* **CLI Cert and Operator Test Coverage** — Added `internal/cli/serve/cert_test.go` (16 tests) for `PerformAutomaticEnrollment`, `RenewOperatorCertificate`, and `RunClientCertRenewalLoop`. Extracted 4 testable units from `RunOperator` at 100% coverage. Overall `cli/serve` coverage at 49.6%.

### Changed

* **Passkey Unification** — Eliminated duplicate login path (`handlePublicAuthLoginVerify`) and unified cookie creation via `setWebSessionCookie` helper. Fixed IDOR vulnerabilities in `ListCredentials`, `RevokeCredential`, and `handleListSuspendedTransactions`. Fixed `readBody` nil `ResponseWriter` bug in `AuthController`.
* **Unified CLI Enrollment** — `performEnroll` replaces platform-specific enrollment paths. `RegisterPasskeyViaBrowser` opens console UI for passkey registration and polls `VerifyPasskeyRegistration` (mTLS) until complete.
* **Console SPA** — Handles `NeedsSetup: true` for first-login passkey registration. Auto-triggers URL-encoded approvals upon successful login.
* **SuspendedTransactionStore Interface Standardization** — Changed `gateway_service.go` and `g8eo.go` suspended transaction fields to interface type (`storage.SuspendedTransactionStore`), retaining concrete `suspendedTxCloser` reference for `Close()` lifecycle.
* **Public Route Registry Cleanup** — Removed deprecated passkey alias routes and `AuthLoginVerify` from public registry. Added SSE consumer endpoints (`/api/v1/sse/stream`, `/api/v1/sse/events`) as public with handler-level dual auth. Added `/api/v1/approvals/status/` as mTLS-excluded prefix.
* **Protocol Python Version** — Updated `protocol/python/pyproject.toml` and `protocol/python/g8e/__init__.py` to v1.3.0.
* **Documentation Updates** — Updated `docs/architecture/auth.md` with Phase 3-5 remediation changes. Updated `docs/architecture/encryption.md`, `docs/architecture/storage.md`, `docs/architecture/sse.md`, and `docs/architecture/gateway.md` for v1.3.0. Updated `docs/devs/codemap.md` with Phase 1-5 remediation changes. Updated `docs/guides/cli.md` for unified enrollment flow.

### Fixed

* **Dead Code Removal in L5Actuator** — Removed `L3Notary`, `SignerStore`, and `Posture` fields from `L5Actuator` struct. These were injected but never read; `L5Actuator` uses `vt.Posture`, `vt.L2Valid`, and `vt.L3Valid` from `VerifiedTransaction` (produced by `L4Warden`) to record receipt status. Added defense-in-depth doc comment explaining the L4/L5 separation boundary.
* **Dual SQLAuditStore Unification** — In outbound mode, replaced standalone `SQLAuditStore` creation with `CanonicalDBService.AuditStore` reuse. Both instances opened the same `g8e.db` file, causing redundant connection pools and potential SQLite contention. Removed `auditStore` field from `g8eService` struct; `CanonicalDBService.Close()` handles lifecycle.

### Removed

* **PasskeyBootstrapServer** — Removed the deprecated localhost bootstrap server (`internal/cli/auth/passkey_bootstrap.go`). Browser-based console flow is now the sole passkey registration path.
* **RegisterPasskeyViaLocalhost** — Removed the CLI-side localhost passkey registration function. All passkey registration goes through the console SPA.
* **Windows Hello WebAuthn Syscalls** — Removed `internal/cli/auth/windows_crypto.go` and related test files. Windows Hello WebAuthn was only used by the localhost bootstrap path. Standard browser WebAuthn via the console SPA is the replacement.
* **Deprecated Passkey Routes and Aliases** — Removed `bootstrap/*` passkey routes, all 8 deprecated alias routes (`cli-register/*`, `cli-browser-register/*`, `cli/authenticate/*`, `browser/authenticate/*`), and the `deprecatedPasskeyAlias` middleware. Removed corresponding API path constants from `internal/constants/api_paths.go` and `protocol/constants/api_paths.json`.
* **mTLS Passkey Register/Authenticate Routes** — Removed `/api/v1/auth/passkeys/register/*` and `/api/v1/auth/passkeys/authenticate/*` routes. These mTLS-only passkey routes were superseded by the browser-based console flow.
* **Dead Error Constants** — Removed `ErrGatewayCLISignatureRequired`, `ErrGatewayMTLSCertFingerprintRequired`, and 12 unused error constants (`ErrGetCurrentUser`, 9 `ErrWindowsHello*`, 2 `ErrWindowsWebAuthn*`).
* **Dead API Path Constants** — Removed 13 deprecated API path struct fields and orphaned values.
* **Dead Excluded Prefixes** — Removed 4 deprecated excluded prefix entries from `PublicRouteRegistry` for routes that no longer exist.
* **HTTPHandlerDependencies.SuspendedStore** — Removed unused field (unused after approval handler consolidation).
