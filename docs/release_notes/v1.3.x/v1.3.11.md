# Release Notes — v1.3.11

**Date:** 2026-07-10

## Overview

v1.3.11 is a test coverage, CLI testability, and Docker E2E reliability release. This version raises the coverage threshold from 70% to 75%, introduces dependency injection patterns across CLI commands for comprehensive unit testing, adds a shared Docker E2E fixture via `TestMain` to eliminate redundant container rebuilds, adds BuildKit cache mounts to the Dockerfile for faster iterative builds, replaces `extra_hosts` with a proper `g8e.local` Docker network alias, adds environment variable resolution for gateway passkey and CORS flags, and removes `demos/airgap.sh` in favor of the existing `g8e demos export/import/images` CLI commands.

## Added

* **Environment Variable Resolution for Gateway Flags** — `resolveGatewayFlags` in `internal/cli/cmd/gateway.go` now resolves `PublicBaseURL`, `PasskeyRpID`, `PasskeyRpName`, `PasskeyRpOrigins`, and `AllowedOrigins` from environment variables when the corresponding CLI flags are not set. New env var constants added to `internal/constants/env_vars.go`: `G8E_PASSKEY_RP_ID`, `G8E_PASSKEY_RP_NAME`, `G8E_PASSKEY_RP_ORIGINS`, `G8E_PUBLIC_BASE_URL`, and `G8E_ALLOWED_ORIGINS`. Comma-separated values are split for slice-type flags (`PasskeyRpOrigins`, `AllowedOrigins`).
* **Docker E2E Shared Fixture** — `TestMain` in `test/e2e/main_test.go` spins up a single Docker Compose stack (gateway + operator) once for all E2E tests, then tears it down after `m.Run()`. The shared fixture is stored in the package-level `sharedFixture` variable. Tests that require Docker check for nil and skip if unavailable; tests that do not require Docker (e.g., MCP config output) run regardless. Eliminates redundant `docker compose up/down/build` cycles that previously caused each test to rebuild the image independently.
* **Dockerfile BuildKit Cache Mount** — Added `--mount=type=cache,target=/root/.cache/go-build` to the `go build` RUN instruction in `Dockerfile`. Preserves the Go build cache across Docker image rebuilds. The E2E harness sets `DOCKER_BUILDKIT=1` to enable this. First run after code changes rebuilds from scratch (~100s); subsequent runs with warm cache complete in ~25s.
* **`g8e.local` Docker Network Alias** — `docker-compose.yml` now assigns `g8e.local` as a network alias on the `g8e-net` network for the gateway service, replacing the previous `extra_hosts: "g8e.local:host-gateway"` on the operator service. This provides proper DNS resolution within the Docker network without relying on host-side `/etc/hosts` entries.
* **`docs/architecture/scripts.md`** — New architecture document providing a central reference for all g8e deployment and bootstrap scripts: dev setup scripts (`linux-setup.sh`, `macos-setup.sh`, `windows-setup.ps1`), gateway-served remote deploy scripts (`g8e-deploy.sh`, `g8e-deploy.ps1`), and air-gap CLI commands (`g8e demos export/import/images`).
* **`docs/guides/cloudflare_tunnel.md`** — New guide for exposing a local g8e gateway to the internet via Cloudflare Tunnel. Covers installation, tunnel creation, routing, DNS configuration, and integration with `g8e gw start --cors-origin`.

## Changed

* **Coverage Threshold Raised to 75%** — `COVERAGE_THRESHOLD` in `Makefile` increased from 70 to 75. The `test coverage` CLI command (`internal/cli/cmd/test.go`) updated to reflect the new threshold in its help text.
* **CLI Dependency Injection for Testability** — `gatewaySettingsCmd`, `operatorListCmd`, and related functions in `internal/cli/cmd/gateway.go` and `internal/cli/cmd/operator.go` now accept injected `configLoader` and `clientFactory` functions instead of calling `loadConfig` and `api.NewClient` directly. This enables unit testing without real config files or network connections. Pattern: `cmdWithConfig(configLoader, clientFactory)` wrappers wrap the production implementations.
* **`osExit` Variable in main.go** — Extracted `os.Exit` call in `ExecuteWithVersionInfo` (`internal/cli/cmd/main.go`) to a package-level `osExit` variable, allowing tests to intercept exit behavior.
* **Demo Scenario Function Refactoring** — Renamed `run*ScenarioWithResult` to `run*Scenario` across all demo scenario files (`demo_dhs.go`, `demo_dow.go`, `demo_finance.go`, `demo_gov.go`, `demo_healthcare.go`, `demo_secure_data.go`, `demo_swarm.go`). Threaded `*cobra.Command` parameter through `runAllScenarios`, `printResultsTable`, `printDemoEndpoints`, `runDemosWithTUI`, and `runDemosRebuild` in `demos.go` to use `cmd.Printf`/`cmd.Println` instead of `fmt.Printf`/`fmt.Println` for test output capture.
* **Posture Validation Moved Earlier** — `ParseGovernancePosture` in `gateway.go` now runs before network identity detection, failing fast on invalid input before any network operations.
* **Gateway Reset/Clean Confirmation Input** — `gateway.go` reset and clean commands now use `bufio.NewReader(cmd.InOrStdin())` instead of `fmt.Scanln` for reading user confirmation, properly handling input with trailing whitespace.
* **Process Manager PID Matching** — `findOperatorProcessWithExecutor` in `internal/cli/platform/process_unix.go` now matches `pgrep` patterns against the data directory (`g8e gateway serve.*--data-dir <dir>`) instead of the generic `g8e gateway serve`, preventing false matches when multiple gateways run on the same host.
* **Docker Compose Health Check** — Gateway service `start_period` reduced from 30s to 5s in `docker-compose.yml` since the gateway typically starts in under 10s.
* **Setup Scripts Improved** — All three platform setup scripts (`scripts/linux-setup.sh`, `scripts/macos-setup.sh`, `scripts/windows-setup.ps1`) now validate the installed Go version against a minimum requirement (1.26+), provide clearer step numbering (3 steps instead of 4), and the Windows script builds install commands dynamically based on which dependencies are actually missing.
* **Protocol Python Version** — Updated `protocol/python/pyproject.toml` and `protocol/python/g8e/__init__.py` to v1.3.11.
* **Air-Gap Guide** — `docs/guides/air_gap.md` updated to reference `g8e demos export/import` CLI commands instead of `demos/airgap.sh`. Added link to new `docs/architecture/scripts.md`.
* **Operator Connection Guide** — `docs/guides/connect_operator_to_gateway.md` updated with link to `docs/architecture/scripts.md` for deploy script details.
* **Getting Started Guide** — `docs/guides/getting_started.md` updated with link to `docs/architecture/scripts.md` for setup script details.
* **Developer Docs** — `docs/devs/devs.md` updated coverage threshold reference from 70% to 75% and added link to `docs/architecture/scripts.md`. `docs/devs/codemap.md` updated with link to `docs/architecture/scripts.md`. `docs/devs/tests.md` updated with Docker E2E fixture documentation.
* **v1.3.5 Release Notes Corrected** — Updated `docs/release_notes/v1.3.x/v1.3.5.md` to accurately reference `g8e demos export/import/images` CLI commands instead of the deleted `demos/airgap.sh` script.

## Removed

* **`demos/airgap.sh`** — Deleted the 160-line shell script. Its functionality (export, import, list) was already superseded by the `g8e demos export`, `g8e demos import`, and `g8e demos images` CLI commands added in v1.3.5. The `make test-airgap` target no longer checks for `demos/airgap.sh` executability.

## Fixed

* **Gateway Reset Confirmation** — `fmt.Scanln` was unable to properly read confirmation input containing spaces or trailing newlines. Replaced with `bufio.NewReader` for robust line-based input reading.
