# Release Notes — v1.3.8

**Date:** 2026-07-08

## Overview

v1.3.8 is a security and usability release. This version replaces raw session identifiers in browser enrollment URLs with one-time enrollment tokens, adds gateway foreground mode for development and debugging, introduces a live swarm demo, improves setup scripts to add g8e to PATH automatically, and hardens the test suite by removing `t.Parallel()` from integration tests and internalizing fixture cleanup.

## Added

* **Enrollment Token Service** — New `EnrollmentTokenService` in `internal/services/gateway/enrollment_token_service.go` generates one-time tokens with a 5-minute TTL for secure passkey enrollment. Tokens are persisted in the `enrollment_tokens` collection, validated and consumed atomically, and cleaned up by a background goroutine every 5 minutes. Added `GenerateToken`, `ValidateAndConsumeToken`, and `CleanupExpiredTokens` methods.

  **How it works:**
  1. After successful CLI enrollment, `RegisterPasskeyViaBrowser` calls `generateEnrollmentToken` via the mTLS endpoint `POST /api/v1/auth/enrollment-token/generate`.
  2. The gateway generates a random 32-byte token (hex-encoded), persists it with the user's `user_id` and `cli_session_id`, and returns it to the CLI.
  3. The CLI opens the browser with `#register=1&token=<token>` (no raw session identifiers in the URL).
  4. The Console SPA reads the token from the URL hash, POSTs it to the public endpoint `POST /api/v1/auth/enrollment-token/validate`.
  5. The gateway validates the token (not expired, not consumed), marks it as consumed, and returns the associated `user_id` and `cli_session_id`.
  6. The SPA populates hidden form fields and calls `registerPasskey()`.
  7. The SPA immediately clears the token from the URL via `history.replaceState`.
  8. A background goroutine (`runEnrollmentTokenCleanup`) runs every 5 minutes to remove expired tokens.

* **Enrollment Token API Endpoints** — Two new gateway endpoints:
  - `POST /api/v1/auth/enrollment-token/generate` — Requires mTLS CLI session. Returns `{ "token": "..." }` with HTTP 201.
  - `POST /api/v1/auth/enrollment-token/validate` — Public (no mTLS required; the token itself is the credential). Returns `{ "user_id": "...", "cli_session_id": "..." }` with HTTP 200. Error responses: 410 (expired), 409 (already consumed), 401 (invalid).

* **Gateway Foreground Mode (`--follow` / `-f`)** — `g8e gw start -f` runs the gateway in the foreground instead of as a background process. Ctrl+C stops the gateway directly. Foreground mode writes network identity to a temp file and calls `serve.RunGateway` directly in the current process, bypassing the process manager's `setsid` background spawning. Useful for development, debugging, and Docker containers where the gateway should be PID 1.

* **Live Swarm Demo** — New demo in `demos/live-swarm/` with `drone_cmd.py` agent script and `tribunal-bootstrap.json` config. Guide at `docs/guides/live-swarm-demo.md`.

* **PATH Setup in Setup Scripts** — `scripts/linux-setup.sh`, `scripts/macos-setup.sh`, and `scripts/windows-setup.ps1` now detect the shell profile (`.zshrc` / `.bashrc` / `.profile` / PowerShell profile) and add the g8e binary directory to PATH. Scripts now have 4 steps instead of 3. The current session is also updated via `export PATH`.

* **Enrollment Token Cleanup Loop** — Background goroutine `runEnrollmentTokenCleanup` in `gateway_service.go` runs every 5 minutes to remove expired enrollment tokens and prevent unbounded collection growth.

* **New Constants and Model** — Added `CollectionEnrollmentTokens` collection name, `ContextKeyCLISessionID` context key, enrollment token error sentinels (`ErrEnrollmentTokenGenerationFailed`, `ErrEnrollmentTokenPersistenceFailed`, `ErrEnrollmentTokenInvalid`, `ErrEnrollmentTokenExpired`, `ErrEnrollmentTokenConsumed`), `EnrollmentToken` model in `internal/models/auth.go`, and enrollment token API path constants.

## Changed

* **Tokenized Passkey Enrollment URL** — `RegisterPasskeyViaBrowser` in `passkey_bootstrap.go` now generates a one-time enrollment token via the mTLS endpoint and opens the browser with `#register=1&token=<token>` instead of exposing raw `user_id` and `cli_session_id` in the URL. Added `generateEnrollmentToken` helper that builds an mTLS client and calls the generate endpoint.

* **Console SPA Token Validation** — Console `index.html` reads the token from the URL hash, POSTs to the public validation endpoint, populates hidden form fields with the returned `user_id` and `cli_session_id`, and immediately clears the token from the URL via `history.replaceState`. Error messages distinguish expired (410 — "This registration link has expired."), already-used (409 — "This registration link has already been used."), and invalid tokens ("Invalid registration link.").

* **Gateway Start Command Refactored** — `gateway.go` restructured to support foreground mode. Process manager creation and operator status check moved to the background-only code path. Foreground mode writes network identity file and calls `serve.RunGateway` directly. The `--follow` flag help text documents the foreground behavior.

* **Process Manager Methods Exported** — `createDirectories` → `CreateDirectories` and `writeNetworkIdentityFile` → `WriteNetworkIdentityFile` exported on `ProcessManager` for use by foreground mode. All internal call sites updated.

* **AuthController Constructor** — `newAuthController` now accepts `*EnrollmentTokenService` parameter. `HTTPHandler` creates the service in `newHTTPHandler` and passes it through. Test setup functions updated to create the service.

* **CLI Session ID in Request Context** — `gateway_auth.go` now stamps `ContextKeyCLISessionID` in the request context for mTLS CLI sessions, enabling the enrollment token generate endpoint to associate tokens with sessions.

* **Documentation** — Updated `docs/architecture/auth.md` with enrollment token flow description (steps 1–8, security rationale for preventing session identifier exposure).

* **Protocol Python Version** — Updated `protocol/python/pyproject.toml` and `protocol/python/g8e/__init__.py` to v1.3.8.

## Security

* **Enrollment Token Security** — Replaced raw session identifiers (`user_id`, `cli_session_id`) in browser enrollment URLs with one-time, 5-minute-TTL tokens. This prevents exposure of sensitive session identifiers in browser history, referrer headers, and screen-share surfaces. Tokens are cryptographically random (32 bytes), consumed on first use, and cleaned up after expiration. The validate endpoint is public (no mTLS) since the token itself provides the authentication context for the browser-based passkey registration flow.
* **Go Toolchain Bump** — Bumped Go from 1.26.4 to 1.26.5 to fix [GO-2026-5856](https://pkg.go.dev/vuln/GO-2026-5856) (Encrypted Client Hello privacy leak in `crypto/tls`). Updated `go.mod`, CI workflows (`.github/workflows/build-and-test.yml`, `.github/workflows/release-go-protocol.yml`), and documentation (`docs/guides/getting_started.md`, `docs/guides/build_gateway.md`, `docs/guides/build_operator.md`, `docs/devs/troubleshooting.md`).

## Fixed

* **Test Fixture Cleanup** — Removed `Cleanup` field from `GatewayFixture` struct. `NewGatewayFixture` now registers cleanup internally via `t.Cleanup()` before returning. Removed all 13 `defer f.Cleanup()` / `defer fixture.Cleanup()` call sites from integration tests. Callers no longer need to defer anything.

* **t.Parallel() Removal** — Removed `t.Parallel()` from all integration-tagged test files (28 files) to prevent resource contention and flaky tests. Integration tests share gateway resources (ports, databases, files) and cannot safely run in parallel.

* **Test Quality** — Replaced hardcoded strings with constants (`constants.VaultDirname`, `constants.SuspendedTxFilename`) in test setup functions for consistency with production code.
