## [2.3.1] - 2026-10-04

### Overview

v2.3.1 is a patch release focusing on UI provider credential decoupling, parallel tool execution in the agent turn loop, call attribution hardening, agent SSE streaming stability, Operator status visibility in the Gateway, workload identity reset support, and developer workflow ergonomics.

### Added

* **Parallel Tool Execution** — Added configurable parallel tool execution in the agent turn loop (`llm_parallel_tool_calls` in `LLMSettings`), allowing independent tool calls returned in a single turn to run concurrently via `asyncio.gather` while maintaining deterministic result ordering and streaming chunk delivery.
* **Operator Visibility in Gateway Status** — Gateway status commands (`g8e status` / `gw status`) now surface registered and enrolled Operators, their assigned roles, and runtime liveness.
* **`g8e ensemble` CLI Command** — Added unified CLI command group for inspecting and interacting with the ensemble runtime directly from the host CLI.
* **Workload Identity Reset** — Added CLI command support for resetting workload identity state.
* **OpenDevOps Enrollment Support** — Added support to facilitate seamless operator enrollment through `enroll.opendevops.ai`.

### Changed

* **Decoupled Provider Credentials from Model Selection in UI** — Separated provider API credentials and connection endpoints from active model selection in the Console UI and user settings models, preventing accidental key clobbering when switching active models across roles.
* **Raw Response Maintenance** — Preserved raw model response structures alongside parsed completion records in agent turn execution for enhanced debugging, token accounting, and trace inspection.
* **Provenance and Observation Operator Separation** — Clarified role contracts, command surfaces, and runtime boundaries between Provenance Operators and Observation Operators.
* **Developer Workflow & Make Targets** — Improved `make up`, `make full`, `make clean`, and repository cleanup targets; streamlined container build profiles and CLI invocation paths.
* **Dependency Updates** — Bumped `github.com/go-webauthn/webauthn` from 0.18.1 to 0.18.2 (#325).

### Fixed

* **Model Call Attribution** — Fixed model call attribution in the agent loop so both parallel and sequential tool calls accurately record execution duration, token counts, and step linkage to the initiating agent turn.
* **Agent SSE Stream Reliability** — Fixed agent Server-Sent Events (SSE) streaming edge cases, preventing dropped chunks or stalled connections during long-running agent tool execution loops.
* **Approval Flow Edge Cases** — Resolved issues with approval request state handling, transaction status synchronization, and multi-step verification.
* **Assignment Audit Events** — Fixed assignment audit event emission and payload indexing in evaluation execution.
* **Disk Usage & Build Cleanup** — Resolved excessive disk consumption in temporary container layers and cache directories; cleaned up redundant build files.
