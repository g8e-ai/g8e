## [2.2.4] - 2026-09-29

### Overview

v2.2.4 is an Evaluation Explorer UX enhancement and inference operator hardening release. It improves assignment detail visibility with expanded activity summary, task prompt sections, and unified grade badges. Evaluation service improvements add platform lane execution, enhanced chat probe infrastructure, improved scenario catalog definitions, and campaign execution refinements. The critical inference operator bug fix detects stale app credentials (certificates no longer issued by the gateway's current trust bundle) and provides actionable guidance for certificate renewal, replacing opaque PROVIDER_FAILED errors.

### Added

* **Evaluation Explorer assignment detail improvements** — Expanded assignment detail view with `AssignmentActivitySummary`, `TaskPromptSection`, `UnifiedGradeBadges` components providing richer task context and outcome visibility.
* **Platform lane execution** — Added `platform_lane.go` and corresponding tests for platform-specific evaluation execution contexts.
* **Chat probe infrastructure** — Enhanced `chat_probe.go` with improved probe definitions and execution support.
* **Improved scenario catalog definitions** — Updated `scenario_catalog_definitions.go` with expanded scenario definitions and improved fixture generation.
* **Campaign execution refinements** — Enhanced `campaign_chat_executor.go` and `campaign_execution.go` with improved chat execution flow and state management, including full test coverage.
* **Inference operator app credential validation** — Added certificate chain validation in `resolveInferenceProbeAppCredentials` to detect when app credentials (g8ee certs) are stale and no longer issued by the gateway's current trust bundle. Provides specific error messages with recovery guidance (docker cp commands) instead of opaque PROVIDER_FAILED errors.
* **Enhanced error messages** — Improved `g8e eval campaigns create` validation messages for `--formations` flag, with clear guidance on comma vs. space-separated formation lists.
* **Per-role transcripts in public assignment detail** — The optional `role_transcripts` extension on public assignment records carries one entry per role (`role`, `response`, `finish_reason`, `trace_digest`, `tool_calls`) lifted from the digest-bound g8ee trace, with each tool call's canonical `arguments_json` and its `arguments_hash`. Tool results are capped at 16 KiB and text matching the restricted-text rule is withheld rather than failing the publish batch. The public disclosure validator enforces a closed field, role, and redaction vocabulary. The Evaluation Explorer renders each role's tool calls, response, and trace digest under its own heading.
* **Formation catalog management** — Added `g8e eval formations add`, `remove`, and `show` alongside `list` and `smoke`, backed by a checked-in catalog overlay (`eval/formation-catalog-overlay.json`) merged with the built-in execution topologies. Formation chat execution and heterogeneous scenario grading were added for formation runs, and observer and provenance behavior in formation witnesses was corrected.
* **Expanded evaluation model inventory** — `eval/base-model-inventory.json` grows from 18 to 75 models, and the rollout intake and model registry were updated to match.

### Changed

* **Role-scoped homogeneous scenario assignment** — Each catalog scenario now declares `eligible_roles` (new `EvaluationScenarioDefinition` field 14, bound by the frozen catalog digest) naming the roles that perform that task in g8ee. `BuildHomogeneousAssignmentMatrix` schedules a scenario only under those roles, so Lite is no longer scored on tool-loop tasks and Primary/Assistant are no longer scored on bounded classification and output-analysis tasks. The standard matrix drops from 75 to 37 assignments per model and the Tier 1 smoke gate from 15 to 8. Catalogs frozen before this field existed fail closed with `ErrEvaluationScenarioRolesUnassigned`, and `ValidateHomogeneousAssignmentMatrix` rejects an assignment for an ineligible role with `ErrEvaluationRoleNotEligible`. The heterogeneous lane is unchanged.
* **Ensemble gateway endpoint environment variables (breaking for deployers)** — `G8E_OPERATOR_URL` and `G8E_OPERATOR_PUBSUB_URL` are renamed `G8E_GATEWAY_HTTPS_URL` and `G8E_GATEWAY_PUBSUB_URL`. `G8E_G8EE_URL` and `G8E_SSH_CONFIG_PATH` are removed. `G8E_GATEWAY_HTTP_URL` is now an optional override that defaults to `http://localhost:8080`. `docker-compose.yml`, `ensemble/.env.example`, and the ensemble settings model use the new names; deployments that set the old names must be updated.
* **Ensemble evaluation trace and grading** — The g8ee evaluation trace service, role control, and agent SSE stream carry additional fields consumed by the Go scenario grader, so grading reflects the recorded g8ee trace.
* **Assignment detail view UX** — Refactored `AssignmentDetailView.tsx` with enhanced layout, improved styling, and new component composition for better visual hierarchy and information density.
* **Selector parsing** — Refined model selector parsing in `selector.go` to better handle edge cases and provide actionable error messages.
* **Scenario fixture generation** — Enhanced `scenario_fixture.go` with improved attachment and metadata generation for evaluation scenarios.
* **Observer and probe execution** — Refined observer integration and chat probe execution patterns.

### Fixed

* **Inference operator app credential staleness** — `resolveInferenceProbeAppCredentials` now validates that the leaf certificate chains to the gateway's current trust bundle before use. When a certificate is no longer trusted (gateway PKI was regenerated after the cert was extracted), the error clearly indicates the cert is stale and instructs users to re-copy the certificate from the ensemble container. Previously, this scenario produced opaque `PROVIDER_FAILED` errors on every assignment in the run.
* **Campaign creation validation** — Corrected error message for invalid `--formations` flag combinations, distinguishing between lane conflicts and model selector conflicts with specific guidance.
* **Run execution error propagation** — Improved error handling in `runs_execute.go` for inference operator session binding and credential resolution.

### Tests

* **Role eligibility** — Added scheduler tests covering per-scenario eligible-role scheduling, rejection of a scenario with no eligible roles, and rejection of an assignment for an ineligible role; updated matrix-size, smoke-gate, and CLI run/verify fixtures to the 37-cell matrix.
* **Inference operator credential validation** — Added comprehensive test suite `eval_inference_test.go` covering:
  * Valid certificate chain verification with trusted CA.
  * Stale certificate detection (cert not signed by current trust bundle).
  * Missing certificate fallback behavior.
  * Trust bundle loading and parsing errors.
* **Campaign chat execution** — Added `campaign_chat_executor_test.go` with unit tests for chat probe execution and state transitions.
* **Campaign execution** — Added `campaign_execution_test.go` with tests for execution flow, error handling, and run state management.
* **Platform lane execution** — Added `platform_lane_test.go` with tests for lane-specific evaluation contexts.
* **Scenario catalog** — Added `scenario_catalog_test.go` with tests for expanded scenario definitions and fixture generation.
* **Ensemble enrollment client** — Added `test/ensemble_enrollment_integration_test.go`, which runs the real Python g8ee enrollment client against a real Gateway: an approved request yields a certificate that chains to the Gateway trust bundle, binds the app and approving-owner SPIFFE identities, and certifies the client's own key; a denied request leaves no credentials. The completion transcript wire format is pinned by `app_enrollment_transcript_contract_test.py` and `TestPlatformEnrollmentCompletionTranscriptGoldenVector`, which assert one shared golden vector in Python and Go. `test_main_lifespan.py` asserts that a failed enrollment aborts startup before any client connects.
