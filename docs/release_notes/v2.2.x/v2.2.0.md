## [2.2.0] - 2026-09-26

### Overview

v2.2.0 is a major platform modernization, architecture refactoring, and documentation standardization release. It modularizes the monolithic g8e CLI into clean Cobra group packages under `internal/cli/cmd/<group>/`, isolates the gateway-embedded Operator substrate into `internal/services/gateway/embedded/`, introduces the dev docs specification and rewrites all maintainer guides in `docs/devs/` to conformant structured markdown with stable invariant IDs, centralizes sentinel errors into `internal/constants/errors.go`, strengthens type safety across live events, harness scenarios, and settings models, improves operator browser and frontend verification, enhances evaluation formation topologies, witness evidence persistence, and Evaluation Explorer telemetry, and includes verified, signed first-party compliance evidence projections.

### Added

* **Modular CLI architecture** — Monolithic command files in `internal/cli/cmd/` are split into cohesive group packages: `audit`, `auth`, `compliance`, `demos`, `docker`, `eval`, `gw`, `gwremote`, `mcp`, `operator`, `public`, `report`, `swagger`, `test`, `tui`, `vault`, and `version`, with shared test fixtures in `cmdtest` and common helpers in `shared`.
* **Embedded Operator substrate package** — In-process Operator lifecycle and pending registration are extracted to `internal/services/gateway/embedded/`, enforcing strict boundary separation between Gateway-embedded and outbound `G8eoService` runtimes (INV-BOUND-04).
* **Dev docs standard and guide rewrites** — Standardized YAML front matter, stable invariant IDs (`INV-*`), quick indexes, owned surfaces tables, procedures, and anti-patterns across `docs/devs/` (`devs.md`, `codemap.md`, `docs.md`, `tests.md`, `troubleshooting.md`, `release_process.md`).
* **Evaluation formation stacks & telemetry** — Support for campaign formation topologies, witness evidence persistence, token metrics, and Evaluation Explorer live event telemetry.
* **Public roadmap** — Added `docs/ROADMAP.md` defining platform roadmap and milestone tracking.

### Changed

* **Centralized sentinel errors** — Reusable platform sentinel errors and failure modes are consolidated into `internal/constants/errors.go` (INV-ERR-01 through INV-ERR-03).
* **Typed domain contracts** — Replaced untyped maps and ad hoc containers with strongly typed models in `internal/models/` and `protocol/models/` for live events, settings, and agent harness scenarios (INV-TYPE-01, INV-TYPE-02).
* **Protocol & Python synchronization** — Protocol packages and specification headers (`protocol/docs/spec.md`, `mcp.md`, `a2a.md`, `constants.md`) synchronized to `v2.2.0` / `2.2.0`.
* **Toolchain streamlining** — Removed redundant `requirements.txt`, aliased proto generation targets, and updated setup scripts in `scripts/lib/dev-setup-common.sh`.

### Fixed

* **Test cleanups & static analysis** — Resolved `errcheck` and `gosec` G114 issues in `internal/cli/cmd/cmdtest/` (`chdir.go`, `reexec.go`) and corrected import formatting across CLI test suites.
* **Gateway connect state machine** — Removed unused imports and verified connection state-machine integration tests.
* **Model provenance manifest resolution** — Hardened Ollama model alias resolution and provider boundary observations.

### Tests

* **Factory error test suites** — Added hermetic file-service initialization failure tests (`factory_error_<group>_test.go`) across all CLI group packages proving fail-closed behavior (INV-FS-08).
* **Gateway integration coverage** — Comprehensive integration coverage for `gw connect`, MCP agent proxying, and evaluation campaign mirror and gate workflows.

### Documentation

* **Complete `docs/devs/` audit & rewrite** — All maintainer guides rewritten to dev docs format with invariant IDs, verified against active codebase.
* **Protocol documentation** — Updated maintained specifications (`spec.md`, `mcp.md`, `a2a.md`, `constants.md`) with version `v2.2.0` and regenerated downstream lockfiles via `make proto`.
