## [2.2.3] - 2026-09-28

### Overview

v2.2.3 is an evaluation CLI restructuring and ergonomics release. It decomposes the overloaded `g8e eval campaign` (1,150 lines) and `g8e eval gate` command groups into eight top-level, resource-oriented command groups: `models`, `campaigns`, `runs`, `rollout`, `formations`, `gates`, `boundary`, and `observer`. Campaign definition (frozen models, scenario catalog, and stack set) is cleanly decoupled from campaign execution (`runs`), with runs managing their own operator session bindings, assignment matrix lifecycle, leases, logs, and public verification. v2.2.3 introduces run leases for tracking active daemon runs, controlled cancellation via `g8e eval runs cancel`, run comparison via `g8e eval runs compare`, campaign and run archiving (`archive` / `unarchive`), unified model selection flags (`--family`, `--max-params`, `--all`), persistent operator session flags (`--inference-session`, `--data-session`) on `g8e eval`, and removes redundant path and `--run-id` flags in favor of positional arguments and project-root scoping.

### Added

* **Eight resource-oriented eval command groups** — Organized under `g8e eval`:
  * `models`: `list`, `show`, `pull`, `freeze`, `add`, `remove`, `import`, `diff`.
  * `campaigns`: `list`, `show`, `create`, `archive`, `unarchive`.
  * `runs`: `list`, `show`, `start`, `resume`, `cancel`, `logs`, `verify`, `publish`, `export`, `repair`, `compare`, `archive`, `unarchive`.
  * `rollout`: `list`, `next`, `add`, `remove`, `retry`, `skip`, `run`.
  * `formations`: `list`, `show`, `smoke`.
  * `gates`: `chat`, `inference`, `probe`.
  * `boundary`: `probe`.
  * `observer`: `run`, `verify`.
* **Campaign & run archiving** — Added `g8e eval campaigns archive/unarchive` and `g8e eval runs archive/unarchive`. Moves campaign specs and completed runs into `.g8e/data/eval/archive/` while retaining offline verification, inspection, and manifest provenance (`evaluation.ArchiveManifest`). Prevents archiving active runs or resuming archived runs (`constants.ErrEvaluationArchived`).
* **Run lease tracking & cancel** — Added run lease tracking (`.g8e/data/eval/runs/<run>/lease.json`) recording process PID, host, start time, and log path during daemon execution. `g8e eval runs cancel` signals the active process, waits for completion of the in-flight assignment, and records cancelled records. `g8e eval runs logs` tails or reads the active run log. `g8e eval runs show` detects live PID status and clears stale leases from crashed processes.
* **Run comparison** — Added `g8e eval runs compare <run1> <run2>`, displaying cell count, verification status, score distributions, and duration deltas between runs.
* **Unified model selection** — Added `ModelSelector` support across `models`, `campaigns create`, and `rollout add`, supporting positional model tags, `--family <family>`, `--max-params <size>`, and `--all`.
* **Persistent session flags** — Added persistent `--inference-session` and `--data-session` flags on `g8e eval`, with automatic single-active-session resolution across enrolled operators when flags are omitted.
* **Public restore positional argument** — Updated `g8e eval public restore` to accept positional `[run-id]` in addition to the legacy flag.

### Changed

* **Separation of campaign definition and run execution** — `g8e eval campaigns create` freezes the campaign spec, scenario catalog, and optional formation stack set. `g8e eval runs start` binds runtime operator sessions and executes the assignment matrix.
* **Positional run identifiers** — Replaced `--run-id <id>` with positional `<run-id>` across all eval run subcommands (`show`, `logs`, `cancel`, `resume`, `verify`, `publish`, `export`, `repair`, `archive`, `unarchive`, `compare`).
* **Rollout queue lifecycle** — Restructured rollout queue commands to `add`, `remove`, `retry`, and `skip`. `rollout run` automatically marks completed and verified entries, and accepts `--until <n>` to bound consecutive executions.
* **Cleaned flag surface** — Removed manual `--queue-file`, `--registry-file`, `--inventory-file`, and `--inventory-dir` flags across eval subcommands. Filesystem discovery is anchored to `--project-root`.
* **JSON support across all leaves** — Every leaf command across all eight eval groups implements JSON output formatting via `output.JSONEnabled` and `output.WriteJSON`.

### Removed

* **Monolithic command groups** — Removed `g8e eval campaign` and `g8e eval gate`.
* **Dev group** — Removed `g8e eval dev`; provider-observer commands relocated to `g8e eval observer`.
* **Legacy staging and materialization commands** — Removed `g8e eval models stage` (replaced by `models pull`) and `g8e eval models materialize` (absorbed into `campaigns create`).

### Fixed

* **Public restore decouple from init campaign queue** — `CampaignMirrorReconciler.ReconcileAllVerifiedRunsFromStore` and `g8e eval public restore` reconcile verified runs directly from the run store and archive manifests instead of requiring `.g8e/eval/init-campaign-queue.json`.
* **Memory service accumulation** — Corrected memory generation service growth during long-running sessions.
* **Tree and file-service invariants** — Enforced child command naming, leaf JSON annotations, and error propagation across the full command tree (INV-CODE-12, INV-ERR-01/02, INV-FS-01/02/08, INV-TEST-ISO-01/02/04).
