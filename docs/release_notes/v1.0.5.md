## [1.0.5] - 2026-05-31

### Overview

v1.0.5 fixes a version mismatch issue where the VERSION file was not updated before the v1.0.4 release was tagged, causing the g8e Node to display v1.0.3 instead of v1.0.4.

### Fixed

* **Version mismatch** - Fixed VERSION file to show correct version in g8e Node. The v1.0.4 release was tagged before VERSION was updated, causing the g8e Node to show v1.0.3. This release ensures VERSION is properly synchronized with the release tag.
