## [1.6.1] - 2026-07-21

### Overview

Gateway HTTP handler decomposition and CanonicalDBService refactor. This release extracts a `Stores` struct from `CanonicalDBService` to enable direct dependency injection of individual store services, decomposes the monolithic `HTTPHandler` into three new single-responsibility controllers (`SSEController`, `HealthController`, `GovernanceController`), and simplifies `make release` to a tag-and-push operation with GitHub Actions workflows handling release creation and asset uploads. Developer documentation (codemap, devs guidelines, architecture docs, system diagram) is updated to reflect the new structure.

### Changed

* **`CanonicalDBService` → `Stores` extraction** — `internal/services/gateway/gateway_db.go`: `CanonicalDBService` is reduced to lifecycle management (database connection, vault, secret manager, background maintenance, close). A new `Stores` struct holds the extracted single-responsibility store services (`DocStore`, `AppPolicyStore`, `SignerStore`, `TribunalStore`, `ReplayStore`, `StateRootSvc`, `KVStore`, `SSEStore`, `BlobStore`, `AuditStore`). `OpenCanonicalDBService` now returns `(*CanonicalDBService, *Stores, error)`. All callers — `GatewayModeService`, `G8eoService`, `internal/cli/serve/gateway.go` — updated to use `Stores` for direct injection instead of accessing store fields through `CanonicalDBService`.
* **`HTTPHandler` decomposition** — `internal/services/gateway/gateway_http.go`: `HTTPHandler` is slimmed to a thin router and middleware shell holding only router infrastructure (rate limiting, CORS, path traversal guard), direct accessors (`passkey`, `mcp`, `pubsub`), and 8 controller fields. Removed 12+ direct service fields (`db`, `pki`, `cliSessionSvc`, `operatorSessionSvc`, `webSessionSvc`, `reg`, `userSvc`, `appEnrollment`, `tribunal`, `envProc`, `isReady`, `isGovernanceReady`, `sseHeartbeatInterval`). Domain handler logic now lives on controllers.
* **`GovernanceController` extraction** — `internal/services/gateway/governance_controller.go` (new, 305 lines): Governance envelope submission, tribunal deliberation, and `SetTribunal`/`SetEnvelopeProcessor` late-bound dependency setters moved from `governance_envelope.go` and `gateway_http.go`. Uses `atomic.Pointer` for tribunal and `atomic.Value` (via `envProcHolder`) for envelope processor, following the thread-safety pattern in `docs/devs/devs.md`. `governance_envelope.go` reduced to the `SetEnvelopeProcessor` delegation method.
* **`SSEController` extraction** — `internal/services/gateway/sse_controller.go` (new, renamed from `gateway_http_sse.go`): SSE event push, poll, and stream endpoints. Includes `authorizeSSERoute` for dual-auth (mTLS or web session) authorization. Heartbeat interval defaults to 30s via `newSSEController`.
* **`HealthController` extraction** — `internal/services/gateway/health_controller.go` (new): Health check, bootstrap health, state endpoint, and landing page. Previously in `gateway_http_health.go` (deleted).
* **`DBController` direct store injection** — `internal/services/gateway/db_controller.go`: Constructor updated to take individual stores (`docStore`, `kvStore`, `sseStore`, `blobStore`, `auditStore`, `signerStore`) instead of `*CanonicalDBService`. All handler methods updated to use direct store fields.
* **`make release` simplification** — `Makefile`: Removed `gh` CLI dependency check, `make build` step, and `gh release create`/`gh release edit` commands. `make release` now syncs Python files, verifies working tree, checks for existing tags, creates `vX.Y.Z` + `protocol/vX.Y.Z` tags, and pushes both tags. GitHub Actions workflows (`release-binary.yml`, `release-python-protocol.yml`) handle release creation and asset uploads.
* **`GatewayModeService.GetStores()`** — `internal/services/gateway/gateway_service.go`: New `GetStores()` method returns the extracted `*Stores` for direct injection. `GetDB()` retained for lifecycle management. All internal references migrated from `ls.db.DocStore` / `ls.db.SignerStore` / etc. to `ls.stores.DocStore` / `ls.stores.SignerStore` / etc.
* **Service constructor signatures updated** — `RegistrationService`, `PasskeyService`, `CLISessionService`, `OperatorSessionService`, `WebSessionService`, `AppEnrollmentService`, `EnrollmentTokenService`, `CLISessionVerifier`, `UserService`, `AuthService`, `PKIAuthority`, `AdminController`, `AuthController`, `PKIController`: All updated to take `*DocumentStoreService` (or individual stores) instead of `*CanonicalDBService`. `PKIController` also had its `db` field removed entirely (no longer needed).
* **Developer documentation** — `docs/devs/devs.md`: Atomic pointer examples updated from `HTTPHandler.tribunal`/`HTTPHandler.envProc` to `GovernanceController.tribunal`/`GovernanceController.envProc`. `docs/devs/codemap.md`: Updated file listings for new/deleted/renamed files, added `SSEController`, `HealthController`, `GovernanceController` descriptions. `docs/devs/release_process.md`: Updated to reflect `make release` simplification (tag-and-push only, GitHub Actions workflows handle release creation). `docs/architecture/gateway.md`: HTTP Router Architecture section updated to describe thin handler + 8 controllers. `docs/diagrams/flowchart-system-overview-lr.md`: Reference updated from `governance_envelope.go` to `governance_controller.go`. `docs/diagrams/sequence-principal-ensemble-gateway-operator-v3.md`: Reference updated from `governance_envelope.go` to `governance_controller.go`. `protocol/docs/spec.md`: Gateway envelope construction reference updated from `governance_envelope.go` to `governance_controller.go`.

### Removed

* **`gateway_http_health.go`** — Deleted; content moved to `health_controller.go`.
* **`gh` CLI dependency from `make release`** — GitHub CLI no longer required for releases; GitHub Actions workflows create releases and upload assets.
* **`make build` from `make release`** — Binary building removed from the release target; CI workflows handle builds.
