## [1.6.2] - 2026-07-24

### Overview

FedRAMP sovereign cloud governance demo, L2 consensus interface decoupling, agent harness refactoring, delegated app enrollment fix, and L2 posture startup validation relaxation. This release adds a new FedRAMP demo with 5 real-governance scenarios exercising the full g8e governance path (L1 doctrine, L2 consensus, L3 notary) for a FedRAMP-authorized cloud service provider. The L2 consensus layer is refactored to decouple the L4 Warden from the Tribunal-specific store — the warden now depends on a generic `L2ConsensusPolicyStore` interface, with the proto field `tribunal_id` renamed to `consensus_set_id` across Go, Python, and JSON schema. The agent harness is refactored with a shared `switchDemoPosture` helper, a typed `shellCommandArgs` JSON builder, and consolidated governance error constants. Demo infrastructure and developer documentation are updated to include the new FedRAMP demo. Additionally, delegated app enrollment is fixed to persist a default AppPolicy (preventing authentication failures for newly enrolled delegated apps), and L2 posture startup validation is relaxed from fail-fast to advisory warnings so the gateway can boot without a pre-configured tribunal.

### Added

* **FedRAMP sovereign cloud governance demo** — `demos/fedramp/`: New demo with Docker Compose topology (`compose.yml`), Sovereign Cloud Service actuator (`cloudsvc.py`, port 9100), operator execution bridge (`cloudop.sh`), verification script (`verify_ops.py`), gateway/operator config, tribunal bootstrap, ensemble seed, FedRAMP doctrine (`fedramp_doctrine.json`), and target data (cloud resources, KSI categories). Gateway ports: HTTP 8088, HTTPS 8451.
* **FedRAMP governance scenarios** — `internal/tools/agent_harness/scenarios/fedramp_governance.go` (new, 256 lines): 5 scenarios exercising real g8e governance for cloud resource operations:
  - `fedramp-provision` — governed cloud resource provisioning with L2 consensus
  - `fedramp-deny` — unauthorized audit trail destruction blocked by L1 doctrine (CR-26)
  - `fedramp-escalate` — resource destruction requires FedRAMP authorizing official approval (L3 notary suspend/approve flow)
  - `fedramp-revert` — governed configuration revert with L2 consensus (CM-7)
  - `fedramp-evidence-block` — gateway audit vault destruction blocked by L1 doctrine (CR-26)
* **`shellCommandArgs` helper** — `internal/tools/agent_harness/scenarios/shell_command.go` (new): Typed JSON builder for `run_shell_command` arguments using `json.Marshal` instead of ad-hoc `fmt.Sprintf`, ensuring proper string escaping per devs.md "no ad-hoc JSON" rule.
* **`switchDemoPosture` shared helper** — `internal/cli/cmd/demos.go`: Extracted from DHS-specific code into a reusable function that restarts the gateway container with a specified posture (`G8E_GATEWAY_POSTURE` env var) and polls the health endpoint until live.
* **`defaultGovernedHarnessConfig` helper** — `internal/cli/cmd/demos.go`: Shared harness config builder for demos using consensus seed and tribunal-based governance (DHS, FedRAMP), wrapping `defaultHarnessConfig` with `ConsensusSeed` and `TribunalID`.
* **Governance error constants** — `internal/constants/errors.go`: `ErrHarnessGovKitNotInit` and `ErrHarnessGovKitMissingSign` replace inline `errors.New` calls across scenario files.
* **`DemosOrgFedRAMP` and `DemosFedRAMPDoctrineFile` constants** — `internal/constants/paths.go`: New constants for the FedRAMP demo org and doctrine file.
* **`FedRAMPScenarioPrefix` constant** — `internal/tools/agent_harness/scenarios/scenario.go`: Scenario prefix for FedRAMP scenarios in the registry.
* **`ErrTribunalNoSigningMembers` error** — `internal/constants/errors.go`: New error returned when a Tribunal deliberation has zero members with private keys available to sign votes.
* **`L2ConsensusPolicy` struct and `L2ConsensusPolicyStore` interface** — `internal/services/governance/tribunal_store.go`: New generic interface and struct that decouple the L4 Warden from the Tribunal-specific `TribunalStore`. `L2ConsensusPolicy` carries `MemberKeyIDs`, `Quorum`, `RequireDistinct`, and `Enabled` — the minimal consensus metadata the warden needs. A `TribunalStoreAdapter` wraps any `TribunalStore` to satisfy `L2ConsensusPolicyStore`.

* **DHS posture switching refactored** — `internal/cli/cmd/demo_dhs.go`: `switchDHSPosture` now delegates to the shared `switchDemoPosture` helper.
* **Demo port and endpoint registration** — `internal/cli/cmd/demos.go`: FedRAMP ports (8088/8451) added to `demoHTTPPort`, `demoHTTPSPort`, `printDemoEndpoints`; `scenarioCounts` map updated with `fedramp: 5`; scenario help text updated.
* **Demo images manifest** — `demos/images.json`: FedRAMP added to `alpine` and `python` image demo lists.
* **Demo README** — `demos/README.md`: FedRAMP section added with topology description, port table, and scenario listing.
* **Developer codemap** — `docs/devs/codemap.md`: FedRAMP scenario files, demo directory, and CLI demo file entries added; `demo_dhs.go` description updated for `switchDHSPosture` rename; `demos.go` description updated with FedRAMP scenario count and `switchDemoPosture`.
* **L2 posture startup validation relaxed** — `internal/cli/serve/gateway.go`: Replaced fail-fast L2 posture validation with advisory warnings. The gateway now starts even when no tribunal is configured or the tribunal policy is missing/disabled. L2 enforcement still happens at transaction time via `L4Warden` — L2-gated transactions are rejected until a tribunal is properly enrolled. This prevents boot failures in fresh deployments where the tribunal has not yet been bootstrapped.
* **L4 Warden decoupled from `TribunalStore`** — `internal/services/governance/l4_warden.go`: The `L4Warden` struct field `tribunalStore` is replaced with `consensusPolicyStore` of type `L2ConsensusPolicyStore`. The `NewL4Warden` constructor parameter changes from `TribunalStore` to `L2ConsensusPolicyStore`. The `verifyL2Posture` method now calls `GetConsensusPolicy` and checks `MemberKeyIDs` instead of `MemberAppIDs`. Error constant `ErrTxL2TribunalNotConfigured` renamed to `ErrTxL2ConsensusNotConfigured`.
* **`GovernanceDeps` field renamed** — `internal/services/pubsub/pubsub_commands.go`: `TribunalStore` field renamed to `ConsensusPolicyStore` (type `governance.L2ConsensusPolicyStore`). Updated in `gateway_service.go`, `test/fixtures/gateway_fixture.go`.
* **MCP gateway deliberator interface renamed** — `internal/services/mcp/gateway.go`: `TribunalDeliberator` interface renamed to `L2ConsensusDeliberator`; `SetTribunalDeliberator`/`getTribunalDeliberator` renamed to `SetL2ConsensusDeliberator`/`getL2ConsensusDeliberator`. Log messages and error strings updated from "Tribunal deliberation" to "L2 consensus deliberation".
* **Proto field `tribunal_id` renamed to `consensus_set_id`** — `protocol/proto/g8e/common/v1/common.proto`: `L2Metadata.tribunal_id` renamed to `consensus_set_id` with updated comments. Generated Go code (`common.pb.go`), Python model (`governance.py`), and JSON schema (`governance.json`) updated. All Go references to `TribunalId` on `L2Metadata` updated to `ConsensusSetId` across `tribunal/service.go`, `agent_harness/client/envelope.go`, `chaos/chaos.go`.
* **Tribunal service `evaluateSafety` simplified** — `internal/services/tribunal/member.go`: `evaluateSafety` and `extractCommandData` no longer take `resource` and `intent` parameters; the safety evaluation now operates solely on doctrine and command data.
* **Tribunal store service implements `L2ConsensusPolicyStore`** — `internal/services/gateway/tribunal_store_service.go`: Added `GetConsensusPolicy` method that loads a `TribunalPolicy` and adapts it to `L2ConsensusPolicy`, allowing `TribunalStoreService` to satisfy both `TribunalStore` and `governance.L2ConsensusPolicyStore`.
* **Consensus verbiage cleanup** — TUI labels, CLI help text, architecture docs, protocol spec, and code comments updated from "Tribunal Consensus" to "L2 Consensus" throughout. `test/tribunal_consensus_integration_test.go` renamed to `test/l2_consensus_integration_test.go`.
* **Duplicate generated proto files removed** — `protocol/proto/protocol/`: Removed duplicate generated `.pb.go` files and API docs that were accidentally nested under `protocol/proto/protocol/`.

### Fixed

* **Delegated app enrollment persists AppPolicy** — `internal/services/gateway/app_enrollment_service.go`: The `handlePKIAppsDelegated` handler previously signed delegated CSRs and returned credentials inline without persisting a default `AppPolicy`, causing `handleAppAuth` to reject the newly enrolled app certificate. The enrollment logic is extracted into a new `EnrollDelegatedApp` method on `AppEnrollmentService` that validates the CSR, signs with dual SANs (app + requestor), and persists a default `AppPolicy` (no L3 approval, unlimited rate, no payload cap) — matching the behavior of `EnrollApp`. A shared `persistAppPolicy` helper is extracted from both methods to eliminate duplication.
* **PKI controller simplified** — `internal/services/gateway/pki_controller.go`: `handlePKIAppsDelegated` now delegates to `appEnrollment.EnrollDelegatedApp` instead of performing validation, signing, and policy persistence inline. Adds nil-check guard for `appEnrollment` dependency. Removes unused `crypto/x509` and `time` imports.
