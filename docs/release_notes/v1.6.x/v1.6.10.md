## [1.6.10] - 2026-08-05

### Overview

Demo cleanup and notary-scenario identity binding release. The gov demo (CUI/CMMC) is removed — its single scenario overlapped with the FedRAMP sovereign cloud governance demo, which now carries the authoritative government compliance narrative. The agent harness now binds notary-scenario transaction submits to the host CLI user identity via a dedicated CLI-cert TLS client, so the suspended transaction and the browser approver share the same user identity end-to-end. The `fileSvcFactory` signature is unified across all `*WithConfig` command functions, the `demo-verify` CI job is removed (the target remains for local use), and several dependency bumps (bubbles v1.0.0, grpc v1.83.0, go-git v5.19.2) land via Dependabot.

### Added

* **CLI-cert TLS client for notary submits** — The agent harness client (`internal/tools/agent_harness/client/client.go`) now builds a second `http.Client` (`cliHTTP`) using the host CLI mTLS material when `CLIAuth` differs from the operator `Auth`. `doWithCLI`/`doWithClient` route notary-scenario transaction submits and the SSE approval subscription through the CLI-cert client so the gateway's `handleCLIAuth` stamps the host user's identity onto the suspended transaction. `MCPToolsCallWithCLI` and `rpcWithCLI` (`client/protocols.go`) are the CLI-cert variants of the MCP/RPC helpers. Affected files: `internal/tools/agent_harness/client/client.go`, `internal/tools/agent_harness/client/protocols.go`.
* **`CLIAuth` harness config field** — `internal/tools/agent_harness/config/config.go` adds a `CLIAuth Auth` field holding the host CLI mTLS material. `Default()` populates `CLIAuth` from `Auth` when not explicitly set, so non-demo invocations work out-of-the-box. Demo invocations override `CLIAuth` via `--cli-cert`/`--cli-key`/`--cli-ca`.
* **`--cli-cert`/`--cli-key`/`--cli-ca` harness flags** — `demos scenarios run` (`internal/cli/cmd/scenarios_run.go`) accepts three new flags that populate `cfg.CLIAuth` via `applyAgentHarnessFlags`. Affected files: `internal/cli/cmd/scenarios_run.go`.
* **`ExtraFlags` map on `harnessConfig`** — `internal/cli/cmd/demos.go` `harnessConfig` gains an `ExtraFlags map[string]string` field for conditionally-present flags emitted as `--<key> <value>` (sorted for deterministic output). `defaultHarnessConfig` seeds `cli-cert`/`cli-key`/`cli-ca` extra flags pointing at the host-creds bind-mount. Replaces the prior `ApprovalURL`/`UserID`/`CLISessionID` dedicated fields. Affected files: `internal/cli/cmd/demos.go`.
* **`withCLIIdentity` governance scenario helper** — `internal/tools/agent_harness/scenarios/governance.go` adds `withCLIIdentity(base)` which copies the host CLI `user_id`/`cli_session_id` from `GovKit` onto the submit persona. Notary scenarios (`governance-notary`, `governance-delegation`) now submit via `MCPToolsCallWithCLI` with the CLI-bound persona. Affected files: `internal/tools/agent_harness/scenarios/governance.go`.
* **`ErrDemoGatewayPortMissing` error sentinel** — New demo error in `internal/constants/errors.go` for when a demo org has no configured HTTP/HTTPS port.
* **`waitForDemoGateway` is now a package-level var** — `internal/cli/cmd/demos.go` exposes `waitForDemoGateway` as a swappable var so tests can substitute a no-op without waiting on a real gateway.

### Changed

* **`fileSvcFactory` signature unified** — All `*WithConfig` command functions now take `fileSvcFactory func(string, *slog.Logger) (fs.RuntimeFileService, error)`, matching `fs.NewRuntimeFileService` directly. The prior `func() (fs.RuntimeFileService, error)` wrapper is removed; `newFileSvc` is now `fs.NewRuntimeFileService` (no wrapper closure). `newDemoFileSvc` is removed (demos call `newFileSvc` directly with the demo directory). Affected files: `internal/cli/cmd/filesvc.go`, `internal/cli/cmd/security.go`, `internal/cli/cmd/test.go`, `internal/cli/cmd/demos.go`, `docs/devs/devs.md`.
* **`hostIdentity` threaded through demo scenario chain** — The package-level `demoIdentity` var is removed. `runDemosRun` now declares a local `hostID` and threads it through `runScenario`/`runAllScenarios`/`runScenarioWithResult` → per-org scenario runners (`runDHSScenario`, `runFedRAMPScenario`). `defaultDHSHarnessConfig`/`defaultFedRAMPHarnessConfig` take a `hostID` parameter and populate `ExtraFlags` (`approval-url`, `user-id`, `cli-session-id`) conditionally. Affected files: `internal/cli/cmd/demos.go`, `internal/cli/cmd/demo_dhs.go`, `internal/cli/cmd/demo_fedramp.go`.
* **`enrollDemoHost` roots fileSvc at demo directory** — `enrollDemoHost` now takes `demoDir` and roots the fileSvc at `demos/<org>/.g8e/` (IQ5 option a) so demo credentials are isolated from the developer's local `<cwd>/.g8e/` state. Sets `HOST_G8E_PKI` env var so docker compose can resolve the bind-mount for the agent container. Affected files: `internal/cli/cmd/demos.go`.
* **Endpoint override access is now mutex-guarded** — `internal/cli/config/config.go` adds `endpointMu sync.RWMutex` guarding `httpEndpointOverride`/`httpsEndpointOverride` against concurrent read/write races between enrollment (which sets and clears overrides) and request handlers (which read them via `OperatorHTTPURL`/`OperatorPublicURL`/`OperatorDiscoveryURL`). All setters and getters now lock accordingly. Affected files: `internal/cli/config/config.go`.
* **`OperatorSessionID` header set on harness requests** — `client.doWithClient` now sets `X-Operator-Session-ID` when the persona carries an `OperatorSessionID`, matching the operator session scoping used by audit receipt queries. Affected files: `internal/tools/agent_harness/client/client.go`.
* **`make demo-verify` removed from CI** — The `demo-verify` CI job is removed from `.github/workflows/build-and-test.yml`. The `make demo-verify` target remains for local use. Affected files: `.github/workflows/build-and-test.yml`, `Makefile`, `docs/devs/tests.md`, `docs/guides/getting_started.md`.

### Removed

* **Gov demo** — The `demos/gov/` directory (compose.yml, config, doctrine, target-data, README) is deleted. The `DemosOrgGov` constant, `DemosGovDir` path, `demo_gov.go` CLI scenario file, `runGovScenario` function, and `gov` entries in `scenarioCounts`/`demoHTTPPorts`/`demoHTTPSPorts`/`printDemoEndpoints` are removed. The `gov_finance.go` scenario file is renamed to `finance.go` and `govFinanceScenarios` to `financeScenarios` (now exports only the `finance-unauthorized-trade` scenario; the `gov-cui-exfil-block` scenario is dropped). The demo count drops from 6 environments / 17 platform demos to 5 environments / 16 platform demos, and the harness scenario count drops from 29 to 28. Affected files: `demos/gov/*` (deleted), `internal/cli/cmd/demo_gov.go` (deleted), `internal/cli/cmd/demos.go`, `internal/constants/paths.go`, `internal/paths/paths.go`, `internal/paths/paths_test.go`, `internal/tools/agent_harness/scenarios/finance.go` (renamed from `gov_finance.go`), `internal/tools/agent_harness/scenarios/finance_test.go` (renamed from `gov_finance_test.go`), `internal/tools/agent_harness/scenarios/scenario.go`, `demos/README.md`, `demos/images.json`, `docs/devs/codemap.md`, `docs/devs/tests.md`, `docs/guides/air_gap.md`, `docs/guides/getting_started.md`, `docs/guides/docker_gateway.md`, `protocol/docs/constants.md`.

### Fixed

* **Endpoint override data race** — `OperatorHTTPURL`/`OperatorPublicURL`/`OperatorDiscoveryURL` could race with `SetEndpointOverride`/`SetHTTPEndpointOverride`/`SetHTTPSEndpointOverride` when enrollment ran concurrently with request handlers. The new `endpointMu` RWMutex serializes access. Affected files: `internal/cli/config/config.go`.

### Security

* **go-git v5.19.2** — Pulls in path-traversal rejection in reference names (`storage/filesystem/dotgit`), symlink-safe filesystem wrapper boundary in worktree operations, and transitive `golang.org/x/net`/`golang.org/x/text`/`golang.org/x/crypto` security updates. Affected files: `go.mod`, `go.sum`, `vendor/github.com/go-git/go-git/v5/`.
