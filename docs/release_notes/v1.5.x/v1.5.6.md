## [1.5.6] - 2026-07-18

### Overview

Lattice gRPC adapter integration, MCP tool interception verification, agent support consolidation, and Python protocol package enhancements. This release introduces a new Anduril Lattice adapter with OAuth2 client credentials authentication and gRPC retry logic, adds pre-launch verification that agent tool-disabling configurations are correctly applied, consolidates supported agents from 12+ to 4 (Claude Code, Codex, Goose, Gemini CLI), and significantly expands the Python protocol package with `GovernanceEnvelope` model, dynamic enums, and `_python_const` fields across all JSON constants.

### Added

* **Lattice gRPC adapter** — New `internal/adapters/lattice/` package providing Anduril Lattice platform integration. Includes `LatticeConfig` with entity model parameters and posture floor validation, `ClientCredentialsAuth` implementing `credentials.PerRPCCredentials` for OAuth2 client credentials flow with proactive token refresh at 2/3 of lifetime with ±10% jitter, `retryWithBackoff` with gRPC status code classification (retryable: Unavailable, DeadlineExceeded, ResourceExhausted, Internal, Aborted, Unknown, NotFound; terminal: InvalidArgument, PermissionDenied, Unauthenticated, etc.), and heartbeat interval validation enforcing < 4 minutes against Lattice's 5-minute soft-state entity expiry. Anduril protobuf definitions added under `third_party/anduril/`.
* **MCP tool interception verification** — New `verifyToolInterception` function in `internal/cli/cmd/mcp.go` checks each agent's tool-disabling configuration before launch. Agent-specific verification: Claude/Codex (MCP config file contains g8e server + launch args include `--disallowed-tools` and `--strict-mcp-config`), Goose (launch args include `--no-profile` and `--with-extension` + `config.yaml` contains g8e extension entry), Gemini (`settings.json` contains `tools.core: []` and g8e MCP server entry). Enabled by default via `--verify` flag; use `--verify=false` to skip for CI/CD pipelines.
* **HeartbeatService sink registration** — `internal/services/pubsub/heartbeat_service.go` now supports `RegisterSink`/`UnregisterSink` for external components (e.g., the Lattice adapter) to piggyback periodic work on the heartbeat scheduler. Sinks are called in registration order after each `SendAutomatic` cycle. Panicking sinks are recovered to prevent heartbeat cycle crashes. `HeartbeatService()` accessor added to `OperatorPubSubService`.
* **Python protocol `GovernanceEnvelope` model** — New `protocol/python/g8e/models/governance.py` with `GovernanceEnvelope`, `GovernanceL1`, `GovernanceL2Vote`, `GovernanceL2`, `GovernanceL3`, and `GovernanceMetadata` models. `compute_transaction_hash()` produces deterministic SHA-256 over pipe-delimited canonical fields (action_type, target_resource, payload, state_merkle_root, nonce, expires_at, intent_data, requestor_user_id, acting_app_id), matching the Go protocol's hash algorithm.
* **Python protocol dynamic enums** — `protocol/python/g8e/enums.py` now generates `StrEnum`/`IntEnum` from protocol JSON constants (channels, intents, prompts, collections, kv_keys, session_types) via `_build_enum()` and `_build_enum_from_dict()`. Access via `g8e.enums.Channel`, `g8e.enums.Intent`, etc. using `__getattr__` with `lru_cache`.
* **`_python_const` fields in protocol JSON** — All `protocol/constants/*.json` files now include `_python_const` keys for Python enum constant name generation. Conformance tests in `protocol/conformance/test_constants.py` validate `_python_const` field presence and SCREAMING_SNAKE_CASE naming.
* **`LLMOverrides` mixin** — `protocol/python/g8e/models/internal_api.py` extracts 12 LLM configuration override fields from `ChatMessageRequest` into a reusable `LLMOverrides` base class.
* **Python protocol accessor functions** — `protocol/python/g8e/constants.py` now exports typed accessor functions: `collection()`, `channel()`, `intent()`, `prompt()`, `kv_key()` (with regex-based dotted-placeholder substitution, e.g. `kv_key("SessionWeb", **{"session.type": "web", "session.id": "abc"})`), and `kv_session_type()`. These resolve constant keys to their wire values.
* **Python event wire model factory methods** — `SessionEventWire` and `BackgroundEventWire` in `protocol/python/g8e/models/events.py` now have `from_session_event()` and `from_background_event()` class methods for construction from event type + data.
* **Lattice config integration** — `internal/config/config.go` `LoadOptions` and `Config` structs now include a `Lattice *lattice.LatticeConfig` field, enabling the adapter to be configured through the standard config loading path. `internal/adapters/lattice/errors.go` defines adapter-local error sentinels and `LatticeEntityIDFilename` constant.
* **`make python-build` target** — New Makefile target copies `protocol/constants/*.json` to `g8e/_data/` and runs `python -m build` for the Python protocol package.
* **MCP gateway output scrubbing** — `internal/services/mcp/gateway.go` now scrubs downstream MCP output via `scrubbingService.ScrubText()` before audit logging to prevent sensitive data leakage.
* **Tests** — Comprehensive test additions: MCP tool interception verification tests (`mcp_tool_interception_test.go`), Lattice adapter tests (`auth_test.go`, `config_test.go`, `retry_test.go`), heartbeat sink tests (`heartbeat_sink_test.go`), MCP agent proxy/prepare launch/error path tests, auth enrollment tests, approve flow tests, factory error tests, Goose config tests. Python tests expanded with `test_enums.py` and `test_models.py`.

### Changed

* **Agent support consolidation** — Reduced supported agents from 12+ to 4: Claude Code, OpenAI Codex, Goose, and Gemini CLI. Removed config path constants and launch support for Cursor, Devin, VS Code, Codeium, Tabby, Continue, and Ollama. `internal/paths/paths.go` `AgentConfigPaths` struct now only has `GeminiConfigDir`, `GeminiConfigPath`, `GooseYAMLConfigDir`, and `GooseYAMLConfigPath` fields. `internal/constants/paths.go` agent config constants reduced accordingly.
* **Goose config approach** — Goose now uses `~/.config/goose/config.yaml` with YAML merge (preserving existing provider and extension settings) instead of `~/.goose` with JSON. Launch args use `--no-profile` (skips all profile extensions including developer extension) and `--with-extension` (loads g8e as sole MCP server).
* **Gemini tool disabling** — Gemini CLI now uses `tools.core: []` (empty array) to disable all built-in tools instead of `excludeTools`, since setting `tools.core` to any value means only listed tools are enabled.
* **L4 Warden payload decoding** — `internal/services/governance/l4_warden.go` `decodePayloadForAction` default case now returns `nil, nil` (raw bytes passthrough) instead of `ErrTxUnknownActionType`, allowing adapter-specific action types to pass through as raw bytes. Unknown action types are still rejected before reaching this function via the known ActionTypes check.
* **CLI test command** — `internal/cli/cmd/test.go` E2E health check now uses `cfg.OperatorDiscoveryURL()` instead of hardcoded `constants.Ports.OperatorHttp` for the health endpoint URL.
* **README.md** — Updated agent list from "Claude / Cursor / Windsurf" to "Claude / Codex / Goose / Gemini". Replaced verbose Status section with concise Contributing section linking to `CONTRIBUTING.md`.
* **CI verify-install checks** — `.github/workflows/release-python-protocol.yml` verify-install job now tests more constants (COLLECTIONS, KV, CHANNELS, INTENTS, PROMPTS) and models (GovernanceEnvelope, compute_transaction_hash) in addition to the previous checks.
* **New error sentinels** — `internal/constants/errors.go` added `ErrAgentNotFound`, `ErrAgentNotInPath`, `ErrAgentNotSupported`, `ErrToolInterceptionVerification`, and several PKI/enrollment-related errors (`ErrCSRGenerationFailed`, `ErrEnrollmentFailed`, `ErrMissingCertificate`, `ErrDirCreateFailed`, `ErrPKIDirRequired`, `ErrCertSaveFailed`, `ErrChainSaveFailed`, `ErrTrustSaveFailed`, `ErrFileServiceInit`, `ErrConfigLoadFailed`, `ErrEndpointRequired`, `ErrGatewayURLRequired`).
* **`TriageClarificationQuestionsPayload` optional fields** — `protocol/python/g8e/models/events.py` `TriageClarificationQuestionsPayload` metadata fields (`complexity`, `complexity_confidence`, `intent`, `intent_confidence`, `intent_summary`, `request_posture`, `posture_confidence`) are now `str | None = None` instead of required `str`.
* **Documentation updates** — `docs/architecture/gateway.md` updated agent list and `--verify` flag docs. `docs/devs/codemap.md` added Python Protocol Package section and updated MCP command description. `docs/guides/build_apps.md` version bumped to v1.5.5. `protocol/python/README.md` updated with accessor functions, new enum categories, governance model, event factory methods, and `LLMOverrides` documentation.

### Fixed

* **PyPI verify-install CDN propagation retry** — The `release-python-protocol.yml` verify-install job was failing intermittently on Windows because PyPI's CDN hadn't propagated the newly published package to all edges. Added a retry loop (6 attempts, 15s apart) to the `pip install` command.
* **Lattice adapter bug fixes** — Error handling and configuration validation fixes in the Lattice adapter across multiple commits.
