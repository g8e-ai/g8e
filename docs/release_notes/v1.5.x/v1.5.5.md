## [1.5.5] - 2026-07-15

### Overview

Hotfix for the Python protocol PyPI package. The `g8e` Python package was missing JSON constants files (`protocol/constants/*.json` and `protocol/constants/doctrine/`) when installed from PyPI, causing runtime failures because `_get_protocol_dir()` could not locate the constants directory. This release adds a CI step to copy the constants into the package's `_data/` directory during the PyPI build and updates the lookup logic to check for bundled files first.

### Fixed

* **Python protocol package missing JSON constants on PyPI** — The `release-python-protocol.yml` workflow did not copy `protocol/constants/*.json` or `protocol/constants/doctrine/` into the Python package before building the sdist/wheel. Added a "Copy protocol constants into package" step that copies the JSON files into `protocol/python/g8e/_data/` prior to the build step.
* **Constants directory lookup logic** — `protocol/python/g8e/constants.py` `_get_protocol_dir()` previously checked only the environment variable, the relative path (dev mode), and a container fallback. Added a new check for bundled files in `g8e/_data/` (the PyPI install path) as the second priority, before the dev-mode relative path and container fallback. This ensures the package works correctly whether installed from PyPI, run from the source tree, or used in a containerized environment.
