## [1.5.2] - 2026-07-15

### Overview

This release adds an interactive onboarding wizard for gateway setup, fixes broken auth re-enrollment in Docker demo environments with split port mappings, and removes the unused `VaultRequireUnlock` config and `testMode` from the gateway service builder. It also fixes vault and rate-limit settings propagation through `GatewayOptions`, relocates `internal/netutil` to `internal/services/network`, and adds a general-purpose GUI frontend enrollment guide.

### Added

* **Gateway onboarding wizard** — `g8e gw start --interactive` (or `-i`) launches a Bubble Tea TUI wizard (`internal/cli/wizard/`) before gateway startup. The wizard guides users through four steps: Network & Identity, Security & Governance Posture, Agent Tooling & Routing, and Review & Confirm. The wizard produces a focused `Config` containing only wizard-owned fields; the `cmd` package merges the result into resolved `GatewayFlags` via `applyWizardConfig`, preserving non-wizard flags (ports, directories, log level, rate limits). Cancellation returns without starting the gateway. The wizard is explicit opt-in only; existing flags and automation continue to work unchanged.
* **`charmbracelet/bubbles` dependency** — Adds `v0.20.0` for `textinput` components used by the wizard. Also adds `github.com/atotto/clipboard` as a transitive dependency.
* **GUI Frontend Enrollment guide** — New `docs/guides/gui_enrollment.md` documents the `g8e gui` command family (enroll, show, verify, remove), gateway-side CORS and passkey RP configuration, WebAuthn flow requirements, SSE integration, TypeScript types, and API reference. The `lovable.md` guide is refactored to reference it instead of duplicating content.

### Changed

* **Split endpoint/port overrides** — The `--endpoint` (`-e`) flag now sets the HTTP discovery endpoint (host or host:port), and `--port` sets the HTTPS/mTLS port independently. When both are provided, the CLI maintains independent overrides for each phase: `SetHTTPEndpointOverride` and `SetHTTPSEndpointOverride` replace the single `endpointOverride` variable. `OperatorDiscoveryURL()` uses the HTTP override; `OperatorPublicURL()` and `OperatorHTTPURL()` use the HTTPS override. This fixes auth re-enrollment in Docker demos where HTTP and HTTPS ports are mapped to different host ports (e.g., 8085→8080, 8448→8443).
* **Gateway startup output** — `printNextSteps` redesigned with hostname display (prefers FQDN from `NetworkIdentity`), explicit Endpoints/Status/Next Steps sections, and GUI/CLI grouping. Adds `pickHostname` helper.
* **Vault and rate-limit propagation** — `serve.RunGateway()` now passes `VaultDir` and `VaultKeyPath` through `config.GatewayOptions` to `config.LoadGateway()` (previously hard-coded to `paths.Infra.*` defaults). Rate limits now flow from `GatewayOptions.RateLimitRPS`/`RateLimitBurst` instead of being zeroed out.
* **`SetKeystore` semantics** — `G8eoService.SetKeystore` now uses dependency injection instead of test-specific `testKeystore` field. The gateway DB uses the injected keystore instead of the OS keychain when set. `SecretManager` is initialized during `OpenCanonicalDBService` and accessed via `GetSecretManager()` instead of being constructed separately in `G8eoService.Start()`.
* **`ReEnroll` signature** — Removed `baseURL` parameter from `ReEnroll()`. The function now always uses `cfg.OperatorDiscoveryURL()` and `cfg.OperatorPublicURL()`, which respect the split endpoint overrides.
* **`netutil` relocation** — Moved `internal/netutil` → `internal/services/network`. All imports updated across CLI, gateway, swagger, and agent harness code.

### Removed

* **`VaultRequireUnlock`** — Removed from `config.Config`, `config.GatewayOptions`, `serve.GatewayConfig`, `constants.EnvVar`, `constants.Errors`, `ProcessManager.BuildReExecArgs`, and `gateway_db.go`. The vault key is now always optional (effectively `VaultRequireUnlock = false`). The `--vault-require-unlock` CLI flag and `G8E_VAULT_REQUIRE_UNLOCK` env var are no longer recognized.
* **`testMode` from gateway service builder** — Removed `testMode` boolean and `withTestMode()` builder method. `newGatewayModeServiceForTest` no longer sets test mode. All `if !b.testMode` guards removed from `build()` — PKI initialization, persona seeding, JWKS provider, and passkey service now run unconditionally. Removed `ErrTestKeystoreNil` error constant.

### Fixed

* **Auth re-enroll broken in Docker demos (#193)** — When the gateway's HTTP and HTTPS ports were mapped to different host ports, a single endpoint override could not address both. The CLI now maintains independent HTTP and HTTPS endpoint overrides, fixing enrollment and re-enrollment in Docker demo environments.
* **Cosign binary signing CI failure (#192)** — Added `id-token: write` permission to `release-binary.yml`. Without it, cosign couldn't get a GitHub OIDC token, fell back to interactive device flow, and timed out after 300s.

### Tests

* New wizard test suite: `model_test.go`, `update_test.go`, `view_test.go`, `steps_test.go`, `validate_test.go`, `run_test.go` — covers wizard state transitions, input validation, rendering, and end-to-end run flow.
* Gateway service builder tests updated to remove `testMode` references and use `SetKeystore` DI pattern.
* CLI config tests expanded for split endpoint override behavior (`SetHTTPEndpointOverride`, `SetHTTPSEndpointOverride`, `SetEndpointOverrideWithPort` with split ports).
