## [1.5.7] - 2026-07-18

### Overview

Test coverage improvement and governance interface refactoring. Raises aggregate test coverage above the 75% threshold enforced by `make test-coverage` (75.9%). Adds approximately 60 new tests across 12 packages, extracts governance interfaces and test fixtures into separate files, and introduces shared test doubles for token storage and results publishing.

### Added

* **Test coverage improvements** — Approximately 60 new tests across 12 packages:
  * `internal/pkg/certutil` — 4 tests for `ParseCertFromPEM` (valid cert, invalid PEM, wrong PEM type, malformed cert bytes)
  * `internal/cli/cmd` — 3 tests for `newFileSvc` and `demo_frontend.go` routing
  * `internal/cli/auth` — 14 tests for passkey bootstrap (enrollment token generation, registration verification), Windows crypto stubs (non-Windows error paths), and mTLS client (valid certs, zero timeout for SSE)
  * `internal/services/fs` — 13 tests for atomic writes (large data, empty, concurrent, nested paths), permissions (nonexistent paths, cancelled context, empty dir), and bootstrap (cancelled context, standard dirs)
  * `internal/services/auth` — Tests for `GenerateSystemFingerprint` and `getMachineIDWithPlatform` unsupported OS branch
  * `internal/services/keystore` — Tests for `StoreMasterKey` invalid key length, `RetrieveMasterKey` invalid base64 and empty key
  * `internal/services/network` — Tests for `getExternalInterfaceIP` error on addrs and loopback-only interfaces
  * `internal/services/pubsub` — Tests for `HeartbeatService.UnregisterSink` (removes sink, nonexistent ID no-op) and `publishHelpers.ExtractContentText` (empty body, nil body)
  * `internal/services/storage` — Tests for `truncateHash` (short hash, empty hash), `suspendedTransactionPrune` (deletes expired, no expired no-error), and ledger functions
* **Shared test doubles** — `storagetest.TestTokenStore` (in-memory `TokenStore` with TTL support) replaces local `fakeTokenStore` in scrubbing tests. `publisherstest.TestResultsPublisher` (thread-safe fake `ResultsPublisher` with recording) provides a reusable pubsub test double.
* **`governancetest` package** — New `internal/services/governance/governancetest/` package with `SimpleTribunalStore`, `SimpleAppPolicyStore`, and `SimpleStateRootProvider` extracted from production governance code. Keeps test-only fixtures out of production binaries.
* **`getMachineIDWithPlatform`** — Extracted from `getMachineID` in `internal/services/auth/fingerprint.go` to accept a `platform string` parameter, making the unsupported OS branch testable without build tags.

### Changed

* **Governance interface extraction** — `l4_warden.go` split into separate files: `replay_store.go`, `state_root_provider.go`, `signer_store.go`, `tribunal_store.go`, `app_policy_store.go`. `TransactionAuditStore` moved from `l5_actuator.go` to `transaction_audit_store.go`. No logic changes — pure file reorganization.
* **Constant export** — `sentinelKeyPrefix` moved from unexported local in `encrypted_kv_adapter.go` to exported `constants.SentinelKeyPrefix`. All references updated including tests.
* **`TokenStore` interface documentation** — Expanded with contract details (encryption, key namespacing, TTL, state tier).
* **`FilesystemSignerStore`** — Removed dead `logger` field from struct. The logger parameter remains in `NewFilesystemSignerStore` for use during construction, but is no longer stored on the struct since it was never read after initialization.
