## [1.5.3] - 2026-07-15

### Overview

Hotfix release for the binary release CD pipeline. The `release-binary.yml` workflow used a broad `bin/g8e-*` glob that matched non-binary files (checksums, signatures), causing incorrect checksum generation and duplicate asset uploads. This release replaces the broad glob with explicit platform-specific patterns.

### Fixed

* **Release binary glob mismatch** — The `release-binary.yml` workflow used `bin/g8e-*` in three places (SHA256 checksum generation, cosign blob signing, and GitHub release asset upload) which matched non-binary files such as `checksums-sha256.txt` and `*.sig` files. Replaced all three occurrences with explicit platform-specific patterns: `bin/g8e-linux-*`, `bin/g8e-darwin-*`, and `bin/g8e-windows-*.exe`.
