## [1.0.12] - 2026-06-10

### Overview

v1.0.12 adds integrated Swagger/OpenAPI documentation management and a new governance reverse proxy for third-party MCP servers. The `./g8e mcp agent run` command wraps any external MCP server in L1 doctrine without requiring the gateway, enabling inline MITRE ATT&CK threat detection for subprocess and HTTP MCP tools. This release also introduces a new `swagger` command group for generating, serving, and validating API documentation.

### Added

* **`mcp agent run` — one command end-to-end** — Launch any supported AI agent under full g8e governance with a single command:
  - `./g8e mcp agent run claude` — Starts the gateway if not running, bootstraps CLI mTLS credentials, then launches Claude with g8e as its exclusive MCP provider (L1-L5 governance via `mcp gov`).
  - `./g8e mcp agent run -- <command> [args...]` — Governance reverse proxy wrapping a subprocess MCP server (L1 MITRE ATT&CK inline screening, no gateway required).
  - `./g8e mcp agent run --url http://localhost:3000` — Same proxy mode for an HTTP MCP server.
  - Named-agent mode: `ensureGatewayRunning()` auto-starts the gateway in `doctrine` posture, polls the plain HTTP health endpoint until ready, calls `auth.BootstrapCLIWithoutPasskey` (idempotent), then uses `--strict-mcp-config` so the agent cannot reach any MCP server other than g8e.
* **Swagger CLI Commands** — New `./g8e swagger` command group for managing OpenAPI documentation:
  - `./g8e swagger init` — Generate Swagger docs from code annotations using swaggo/swag
  - `./g8e swagger serve` — Serve Swagger UI for interactive API documentation
  - `./g8e swagger validate` — Validate Swagger/OpenAPI specification for compliance
* **Gateway Swagger UI** — The gateway now serves Swagger UI at `https://localhost:8443/swagger/index.html` for interactive API testing and exploration.
* **Swagger Integration** — Uses existing swaggo/swag dependency (v1.16.6) with automatic fallback to `go run` if the `swag` binary is not installed.

### Changed

* **Gateway HTTP Handler** — Updated Swagger UI handler to use `httpSwagger.Handler` with proper configuration options (URL and DocExpansion).
* **CLI Documentation** — Updated CLI reference documentation to include the new swagger command group.

### Fixed

* **Swagger Handler Configuration** — Fixed incorrect usage of `httpSwagger.WrapHandler` that was causing build errors. Now correctly uses `httpSwagger.Handler` with configuration functions.
