## [2.1.1] - 2026-08-30

### Overview

v2.1.1 is a maintenance patch that bumps the WebAuthn, gRPC, and `golang.org/x/net` dependencies, regenerates the gateway Swagger specification from the upgraded WebAuthn library, and refreshes the ensemble Python dependency pins. No wire protocol, on-disk format, CLI surface, or governance behavior changes.

### Changed

* **WebAuthn dependency upgrade** — Bumped `github.com/go-webauthn/webauthn` from v0.17.4 to v0.18.0 and the transitive `github.com/go-webauthn/x` from v0.2.6 to v0.3.0. The upgrade brings typed WebAuthn extension inputs, related-origins support, client capabilities, and the secp256k1 crypto subsystem into the vendored tree.
* **gRPC and `golang.org/x/net` bumps** — Bumped `google.golang.org/grpc` from v1.83.1 to v1.83.2 and `golang.org/x/net` from v0.57.0 to v0.58.0, pulled in by the WebAuthn upgrade.
* **Regenerated gateway Swagger specification** — `internal/services/gateway/docs/swagger.json` and `swagger.yaml` regenerated from the upgraded WebAuthn library. `protocol.AuthenticationExtensions` now documents explicit typed properties (appid, appidExclude, credBlob, credProps, credentialProtectionPolicy, enforceCredentialProtectionPolicy, getCredBlob, hmacCreateSecret, hmacGetSecret, largeBlob, minPinLength, prf, remoteClientDataJSON, uvm) instead of an untyped `additionalProperties: {}` map, and new definitions for `CredentialProtectionPolicy`, `HMACGetSecretInputs`, `LargeBlobInputs`, `LargeBlobSupport`, `PRFInputs`, and `PRFValues` are emitted. The ML-DSA COSE algorithm identifiers (-48, -49, -50) are removed from the `COSEAlgorithmIdentifier` enum, matching the upstream library's unsupported-status handling for post-quantum signature algorithms.
* **Ensemble Python dependency refresh** — Bumped pinned ensemble dependencies: `pydantic` 2.12.5 to 2.13.4, `cryptography` 50.0.0 to 50.0.1, `protobuf` 7.35.1 to 7.36.0 (and 6.33.6 to 7.36.0 in `requirements.txt`), `grpcio-tools` 1.80.0 to 1.83.0, `google-genai` 2.0.1 to 2.20.0, `anthropic` 0.120.0 to 1.2.0 (and 0.100.0 to 1.2.0 in `requirements.txt`), `mkdocs` 1.6.0 to 1.6.1, `sentence-transformers` 2.2.0 to 6.0.0, `ruff` 0.15.12 to 0.16.5, and `pytest-asyncio` 1.3.0 to 1.4.0. Lock files (`ensemble/uv.lock`, `ensemble/evals/uv.lock`) regenerated.
* **CI Node setup action** — Bumped `actions/setup-node` from v5 to v7 in `.github/workflows/build-and-test.yml`.

### Fixed

* **Swagger extension typing** — The `AuthenticationExtensions` schema previously rendered as an opaque `additionalProperties: {}` map; it now carries the typed extension input properties defined by the WebAuthn library, giving API consumers accurate request shapes for passkey registration and assertion extensions.

### Notes

* No wire protocol, on-disk format, CLI surface, or Python package source changes. The Go protocol module and Python package are re-versioned only.
* The ML-DSA COSE algorithm identifier removal in the Swagger enum reflects the upstream WebAuthn library marking post-quantum signature algorithms as unsupported; g8e does not expose ML-DSA credential algorithms on its WebAuthn notary surface.
