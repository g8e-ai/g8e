## [2.1.14] - 2026-09-25

### Overview

v2.1.14 is the event-and-action protocol cleanup release. Callers name a registered request `event_type`; the Gateway derives `action_type` from `protocol/constants/events.json`. New ingress uses hash and receipt canonicalization v2. Operator and Gateway audit logs are hash-chained. LFAA records ingest over HTTP with `{seq, hash}` acknowledgement. g8ee talks to the Gateway over HTTP only.

### Breaking

* **Dispatch is event-first** — `POST /api/v1/operators/commands` and MCP/A2A governed calls take `event_type`. The registry supplies `action_type`. Unknown events fail closed at Gateway ingress.
* **Transaction hash v2** — New envelopes set `protocol_version=2`. The v2 canonical string includes `event_type`. Ingress rejects other versions. Verifiers keep v1 only for historical stored records.
* **Receipt canonical v2** — `ActionReceipt` carries top-level `event_type` and `action_type`, included in receipt canonicalization.
* **Thinking payload field** — `thinking_action_type` / payload `action_type` is `thinking_phase` / `phase`.
* **Renamed wire events** — `g8e.v1.ai.llm.chat.filter.updated`, `g8e.v1.operator.command.execution.started`, `g8e.v1.operator.command.result.completed`, `g8e.v1.platform.auth.info.updated`, `g8e.v1.platform.notification.sent`.
* **Removed** — `g8e_action_type`, `action_status`, fabricated `*_RESULT` classifiers, g8ee pub/sub (`CommandIntent` construction), and the grammar allowlist.

### Added

* **MCP list request events** — `OperatorMcpResourceListRequested` and `OperatorMcpPromptListRequested` complete the MCP governed-action registry. Resource read, prompt get, and list have L5 handlers.
* **Audit ingest** — `POST /api/v1/audit/records` and `./g8e audit verify [--from-seq]`.
* **SSE registry gate** — Gateway push rejects unregistered / non-sse / wrong-producer events (422) and skips ephemeral persistence.
* **Architecture lints** — Go and Python tests fail on `g8e.v1` literals, mapper names, and banned leftover vocabulary.

### Changed

* **One registry** — `events.json` is the source of truth. `make constants` / `make constants-check` generate Go, dashboard JS, and the bundled Python `_data/events.json`. Grammar is enforced with an empty allowlist. `*.status.updated.<state>` is an explicit grammar form.
* **g8ee** — Operator authority, heartbeat persistence, and pub/sub are gone. Application tools dispatch through `GatewayOperatorClient`.

### Tests

* MCP resource/prompt event-type envelope tests and MCP list/read/get handler fail-closed tests.
* E2E: unknown-event dispatch 400, audit verify, LFAA ingest ack, chat file-create receipt `event_type`/`action_type` plus receipt v2 canonicalization, chat case-create `g8e.v1.app.case.create.requested`.
* Audit chain tamper detection reports the exact sequence number.
