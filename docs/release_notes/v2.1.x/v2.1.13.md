## [2.1.13] - 2026-09-24

### Overview

v2.1.13 is a focused evaluation UX, rollout ergonomics, and provider-boundary correctness release. It compacts the Evaluation Explorer assignment-detail view, adds a public Tasks catalog for the north-star-25 scenario set, replaces the `--tier-a` witness preset with `--require-witness`, makes strict witness verification the default on `g8e eval rollout run`, adds Hugging Face rollout staging and abandoned-run discard helpers, hardens Ollama manifest resolution for untagged and HF-served models, records optional Ollama cache-token telemetry without inflating totals, scales campaign mirror reconcile timeouts with assignment volume, and adds `g8e auth enroll list` for completed platform enrollment review and revocation. It does not claim external public-mirror capacity acceptance, delegated-provider formation execution, or full cross-language thinking/cache telemetry propagation.

### Added

* **Evaluation Explorer Tasks catalog** — New `/tasks` routes list the frozen north-star-25 scenarios by behavior category with disclosure-safe prompts, pass criteria, tool boundaries, and source links to the checked-in catalog.
* **Compact assignment detail** — Assignment detail uses a compact mast, verdict strip, measured and score rows, conditional activity and feed timeline, and sibling repetition links. Empty sections and values absent from the public record are omitted.
* **Public assignment event projection** — Explorer reconstructs live assignment lifecycle events from published public feed records without inventing prompts, outputs, or credentials.
* **Platform enrollment list** — `g8e auth enroll list` and `GET /api/v1/auth/platform-enrollments/enrolled` return completed and revoked enrollment metadata (request ID, component kind, instance ID, hostname, state) for owner review and `g8e auth enroll revoke`.
* **Hugging Face rollout staging** — `g8e eval models stage` reads `eval/rollout-intake-hf.json`, pulls GGUF models through Ollama's HF compatibility, and applies canonical served-model aliases with `/api/copy`.
* **Abandoned rollout discard** — `g8e eval rollout discard` removes scheduled init-campaign runs that never started executing, clears failed queue references, deletes publication idempotency, and hides runs from the public mirror. Verified queue entries are never discarded.
* **Ollama cache-token boundary** — The Ollama backend accepts optional `prompt_eval_cached_count`, maps it to signed `CacheTokens` when present, preserves `ThinkingTokens == nil` when thinking text exists without a count, and does not add cache tokens to `total_tokens`.
* **Shared Ollama name parsing** — `internal/ollama` centralizes canonical served-tag parsing for manifest lookup across provenance attestation and staging helpers.

### Changed

* **Witness preset rename** — `--tier-a` is removed. Use `--require-witness` on `g8e eval campaign start` and related commands. On `g8e eval rollout run`, `--require-witness`, `--verify`, `--publish`, `--daemon`, and `--skip-verified` all default true.
* **Assignment detail presentation** — Campaign `unverified` maps to `not_run` in the UI; completed assignments use terminal status for the mast label; `scenario_not_applicable` tool dimensions are filtered; thinking and cache token rows render only when `resource_summary` contains a value.
* **Model provenance manifest resolution** — Provenance attestation resolves untagged aliases (`glm-5.3-flash`), tagged library models, registry namespaces, and Hugging Face deep pulls under their on-disk manifest paths using Ollama's canonical name parser.
* **Campaign mirror reconcile timeouts** — Mirror restore scales per-run deadlines with assignment count (base 5 minutes plus 2 seconds per assignment, capped at 20 minutes). Docker init performs a shorter presence check rather than a full restore.
* **Platform enrollment submission** — Governance envelope submission retries when concurrent enrollment CREATE activity advances the bound state root.
* **Public mirror campaign probing** — Gateway mirror restore checks for campaign dataset projections before reconciling verified queue entries.

### Fixed

* **Provenance manifest lookup** — Untagged and HF-served model aliases no longer fail with `invalid served model tag` or `manifest not found` when the model exists on the provider host.
* **Platform enrollment edge cases** — Empty-token status queries fail closed; concurrent enrollment envelope submission tolerates state-root advancement within bounded retries.
* **Formation input-token publication** — Heterogeneous formation execution preserves provider-reported prompt usage through role telemetry, persisted formation evidence, recovery, public resource summaries, and Explorer Live Events instead of publishing an observed zero.
* **Go formatting** — `gofmt` findings in campaign abandoned-run, rollout intake, and public mirror campaign files are corrected.
