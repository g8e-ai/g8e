## [2.1.12] - 2026-09-22

### Overview

v2.1.12 is an evaluation evidence, public projection, and platform enrollment correctness release. It advances the Evaluation Explorer contract to schema 1.5.0 headline metrics with population-bound verification metadata, preserves authoritative verification through later aggregate and mirror reconstruction, hardens the gateway-owned public spectator deployment, repairs organization-bound platform enrollment identities, and makes size-ordered campaign inventory materialization deterministic and immutable. Live acceptance covers two fresh 75-assignment campaigns on the qualified four-Operator topology; it does not claim completion of the broader 45-model rollout.

### Added

* **Typed Evaluation Explorer headline metrics** — Campaign summaries expose pass rate, latency p50, and output-throughput p50 with explicit units, applicability, observed/eligible/unavailable contributor counts, unavailable reasons, and population-bound verifier metadata under view schema 1.5.0.
* **Bound verification projection** — Passing and failing campaign reports bind report and population digests, verifier versions, and verification time into aggregate, completion, catch-up, export, bootstrap, history, snapshot, and SSE projections.
* **Organization-backed enrollment identity** — User creation persists the canonical single-user organization and membership, while Operator issuance resolves that membership and binds organization and user identities into Operator and companion CLI certificates, documents, and sessions.
* **Size-ordered rollout inventories** — `g8e eval rollout init` orders typed model variants by ascending parameter count with deterministic tag and variant tie-breakers and materializes immutable per-model inventory freezes.

### Changed

* **Campaign aggregate ownership** — `CollectRunAggregateState` derives all schema-1.5.0 metrics from canonical assignment results, and fresh campaign export persists the same projector-owned `evaluation_summary.json` used by publication instead of implementing a second aggregation path.
* **Verification monotonicity** — Later unverified aggregate revisions retain an applicable bound `passed` or `failed` state and metadata. Malformed or population-mismatched persisted reports fail closed instead of publishing a downgrade.
* **Public mirror topology** — Unified Compose binds private ingest, anonymous public read, and Evaluation Explorer host ports to loopback; trusts only the fixed Docker bridge gateway CIDR for a single valid unicast `CF-Connecting-IP`; raises the Gateway file-descriptor limit to 16,384; and uses `unless-stopped` recovery without deleting mirror state.
* **Public-feed reconstruction** — Gateway integration coverage compares canonical completion and verification projections with signed mirror history, bootstrap, snapshot, and SSE replay, while Explorer reconstruction preserves unavailable-only metrics without inventing numeric zeroes.
* **Campaign source discipline** — The release evidence source is the fresh append-only `v2-1-12-size-ordered-20260923` generation. Interrupted runs from archived sources remain diagnostic evidence and are not relabeled or resumed.

### Fixed

* **Malformed platform SPIFFE identities** — Platform enrollment no longer issues identities with an empty organization segment. Missing or inconsistent organization state now fails closed before certificate and session issuance.
* **Dry-run-to-start inventory conflict** — Campaign start accepts an identical existing read-only inventory freeze idempotently, atomically writes a missing freeze, and rejects differing immutable content with `ErrImmutableInventoryConflict`.
* **Stale producer schema** — The Go aggregate producer now emits the current schema 1.5.0 contract rather than schema 1.3.0 while historical schema versions remain readable.
* **Proxy identity spoofing** — Forwarded visitor identity is ignored unless the immediate peer is in an explicitly configured trusted CIDR and the request supplies exactly one valid unicast address.
* **Publication/export drift** — Verified catch-up and fresh export load the persisted bound report and preserve matching report digest, population digest, metric values, units, coverage, unavailable reasons, and verifier state.
