## [2.1.9] - 2026-09-19

### Overview

v2.1.9 hardens eval campaign execution for the Tier-A init rollout: gateway-side model provenance preflight catches storage and delivery gaps before assignments start, namespaced Ollama models resolve the correct manifest paths, and `docker init` restores verified campaign mirrors after gateway volume wipes. g8ee inference-dispatch HTTP timeouts are aligned with long Ollama runs, and trace import no longer mislabels pre-inference failures as partial completions.

### Added

* **Model provenance preflight API** — Gateway read endpoints `…/model-provenance/attestations/_preflight` and `…/model-provenance/attestations/_attest` verify provenance command delivery and storage-side attestation readiness for a `served_model_tag` + `expected_model_digest` pair before execute begins.
* **Execute-time provenance preflight** — `g8e eval campaign execute` and orchestrated rollout paths call delivery and per-model attestation preflight when Tier-A provenance is required, failing fast instead of completing assignments with missing windows.
* **Automatic mirror restore on `docker init`** — After platform enrollment completes, `g8e docker init` attempts `g8e eval campaign mirror restore --queue` when host queue and run artifacts exist.

### Changed

* **Namespaced Ollama manifest resolution** — Storage attestor resolves `namespace/model:tag` served tags to `manifests/registry.ollama.ai/<namespace>/<model>/<tag>` instead of assuming the `library/` namespace (fixes Tier-A provenance for models such as `Impulse2000/smollm3:3b-q4_k_m`).
* **`docker init` enrollment approval order** — Auto-approval waits for the next slot in documented order (data operator → dashboard → ensemble → inference operator) even when workloads submit requests out of order; approval API client timeout raised to 30 seconds during bootstrap.
* **g8ee inference-dispatch timeout** — `INFERENCE_DISPATCH_HTTP_TIMEOUT_SECONDS` raised from 30s to 330s so governed chat dispatches can complete long Ollama inference without client-side abort.
* **Documentation** — Unified stack and `eval/examples/README.md` document mirror-restore workflows after gateway volume wipes and `campaign publish --force` when idempotency keys block republication.

### Fixed

* **Pre-inference trace classification** — Terminal g8ee traces with `status=failed` and zero `model_calls` import as `PROVIDER_FAILED` instead of `PARTIAL`, so verify and rollup counts reflect assignments that never reached governed inference.
* **Tier-A provenance 404s on namespaced models** — Manifest path and execute-time preflight prevent campaigns from completing 75/75 assignments while verify reports permanent provenance gaps.

### Deferred

* **Init campaign matrix completion** — Tier-A batch rollout (`11/35` verified as of release prep) continues on the campaign host; this release ships the hardening fixes, not a completed 35-model matrix claim.
* **Owner-operated gates** — Browser WebAuthn, cross-platform trust, builder SPAs, and `./g8e test e2e` remain outside automated CI.

### Tests

* Unit and flow tests cover namespaced manifest resolution, provenance preflight handlers, `docker init` approval slot selection, trace `PROVIDER_FAILED` classification, and campaign orchestration preflight wiring. Platform and ensemble test matrices are release-owner / CI gates for this patch.
