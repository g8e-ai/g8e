## [2.1.11] - 2026-09-20

### Overview

v2.1.11 hardens recovery of the gateway-owned evaluation mirror when host campaign publication state outlives a wiped or incomplete mirror dataset. It also improves the Evaluation Explorer's campaign progress and initial history-reconciliation presentation so public data remains understandable while the feed is being rebuilt.

### Changed

* **Drift-aware campaign catch-up** — Campaign publication probes the gateway-owned dataset before catch-up and clears stale host publication idempotency only when the canonical dataset is absent, allowing verified campaign records to be republished without manual edits to host state.
* **Verified mirror reconciliation** — Queue and run restoration use the persisted verification report when available, preserving verified assignment and model-summary publication together while retaining a legacy-report fallback for older campaign state.
* **Evaluation Explorer presentation** — The overview and campaign adapter render public campaign progress from typed feed records and keep history reconciliation visible during initial loading instead of presenting incomplete progress as settled state.
* **Documentation** — Updates the evaluation, public spectator, and unified-stack guidance with the current mirror recovery behavior and operational commands.

### Fixed

* **Empty explorer after mirror-volume recovery** — Restored verified runs now republish canonical lifecycle, terminal, aggregate, and verification projections when host idempotency state still claims they were published but the gateway-owned dataset is missing.
* **Mirror recovery quality drift** — A missing public dataset no longer prevents verified catch-up from restoring the stored quality-state revisions required by the explorer.

### Tests

* Added campaign mirror reconciler coverage for queue restoration, single-run restoration, present-dataset skipping, legacy verification reports, and CLI restore paths.
* Verified the Go unit suite, Evaluation Explorer adapter tests, TypeScript typecheck, and Evaluation Explorer lint.
