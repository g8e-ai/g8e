## [2.1.11] - 2026-09-20

### Overview

v2.1.11 is an evaluation campaign reliability release. It replaces disruptive per-assignment provider daemon management with governed model release through the exact Inference Operator, adds typed residency and unresolved-assignment safety, records a fresh 75/75 Tier-A campaign with provider observation and model provenance, and advances serial rollout continuation. It also hardens recovery of the gateway-owned mirror and corrects Evaluation Explorer transport and progress handling for the resulting public feed.

### Added

* **Governed model-residency release** — Campaign boundaries release only campaign-owned resident models through the existing typed `EXECUTE_BASH` path, the exact Inference Operator, the image-baked `/g8e operator model release <served-tag>` command, and the embedded `OllamaBackend`; the provider Observer remains a read-only telemetry witness.
* **Serial Tier-A rollout continuation** — `g8e eval rollout run` executes queued model campaigns with provider-observation and model-provenance requirements, skips verified entries, records per-model logs and outcomes, and can continue ordinary model failures without bypassing lifecycle or evidence gates.
* **Fresh Tier-A campaign evidence** — The `qwen3:0.6b` campaign completed 75/75 terminal assignments with zero population-accounting failures and passed independent Tier-A verification with both witness requirements.

### Changed

* **Campaign lifecycle policy** — Same-model assignments retain provider residency without daemon resets or stable-body `/api/ps` sleeps. Model changes and normal completion use typed named-model absence checks and bounded governed release; no external Ollama CLI, curl backend, or Observer management authority is used.
* **Witness boundaries** — Observer and Provenance Operators are read-only witness sessions for generic command execution at Gateway admission and outbound Operator execution. Inference-only model maintenance carries the approved provider endpoint through the existing typed command environment.
* **Campaign orchestration and safety** — Standalone execute and start/rollout use the shared execution loop, preserve JSON summaries, fail closed on unresolved persisted `RUNNING` assignments, and derive completion cleanup from persisted run state rather than in-memory counters.
* **Rollout and evidence inspection** — The completed 75-cell run exported 75 assignments and three model summaries; mirror/export assignment IDs matched, disclosure scanning found no prohibited public fields, and the next serial rollout verified `ministral-3-3b` before advancing to `ministral-3-8b`.
* **Drift-aware campaign catch-up** — Campaign publication probes the gateway-owned dataset before catch-up and clears stale host publication idempotency only when the canonical dataset is absent, allowing verified campaign records to be republished without manual edits to host state.
* **Verified mirror reconciliation** — Queue and run restoration use the persisted verification report when available, preserving verified assignment and model-summary publication together while treating legacy verdict-only reports as unavailable verification metadata rather than claiming a current verification pass.
* **Evaluation Explorer presentation** — Bootstrap normalization now removes transport-only fields, canonical protojson `null` repeated values are accepted, completed-event progress is capped at the resolved matrix total, and history reconciliation remains visible during initial loading.
* **Documentation** — Updates evaluation, operator, ensemble-evaluation, public spectator, and unified-stack guidance to describe the governed Inference-Operator release path and current mirror recovery behavior.

### Fixed

* **Per-assignment daemon reset** — Evaluation no longer restarts or kills the provider daemon before every cell, avoiding orphaned runner accumulation and disruptive reset sleeps.
* **Provider timing conversion** — Decimal provider timings are rounded to the nearest nanosecond before checked uint64 conversion, preventing valid fractional durations from becoming false verification failures.
* **Empty explorer after mirror-volume recovery** — Restored verified runs republish canonical lifecycle, terminal, aggregate, and verification projections when host idempotency state claims publication but the gateway-owned dataset is missing.
* **Mirror recovery quality drift** — A missing public dataset no longer prevents verified catch-up from restoring stored quality-state revisions required by the explorer.
* **Unresolved assignment replay** — Persisted assignments left in `RUNNING` without terminal evidence are no longer silently retried as new scored attempts.

### Tests

* Current gates passed for the Go unit suite, focused Evaluation/CLI/Gateway/Inference/PubSub/Operator capability/Execution integration packages, `make build`, `./g8e test lint`, contract-pack drift, and the Evaluation Explorer suite (327 tests), typecheck, lint, and production build.
* Campaign acceptance recorded 75/75 Tier-A execution and independent verification, mirror/export parity across 75 assignments, disclosure scanning, and the first verified serial rollout entry.
