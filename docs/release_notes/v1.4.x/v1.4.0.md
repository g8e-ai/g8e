# Release Notes — v1.4.0

**Date:** 2026-07-12

## Overview

v1.4.0 is a feature release introducing frontend application enrollment, Cloudflare Tunnel management, and significant gateway API documentation. New `g8e gui` and `g8e tunnel` command suites enable external frontend integration and public gateway exposure without firewall changes. The L5 Actuator is refactored to remove its direct `ExecutionService` dependency in favor of a cleaner `ExecutionHandler` interface. OpenAPI/Swagger annotations are added across all gateway endpoints. The `operator run` command is renamed to `operator start`, and running `g8e` with no arguments now launches the TUI by default.

## Added

* **`g8e gui` Command Suite** — New CLI command (`internal/cli/cmd/gui.go`) for enrolling external frontend applications (React, Lovable, custom apps) with the g8e Gateway. Subcommands: `enroll` (register an origin in the local enrollment file and verify gateway CORS/passkey flags), `show` (list enrolled origins), `verify` (check gateway configuration against an enrolled origin), and `remove` (delete an enrollment). Enrollment persists to `gui_enrollments.json` in the g8e data directory. The gateway is not restarted during enrollment — it must be started with the correct `--cors-origin` and `--passkey-rp-origin` flags beforehand.
* **`g8e tunnel` Command Suite** — New CLI command (`internal/cli/cmd/tunnel.go`) for managing a Cloudflare Tunnel that securely exposes the local g8e Gateway to the internet without opening firewall ports. Subcommands: `create` (create a named tunnel, route DNS, generate `config.yml`), `run` (start the tunnel in foreground), and `status` (check tunnel connectivity and gateway health through the tunnel). Requires `cloudflared` installed on PATH.
* **`g8e demos run` Scenarios Command** — New `demos run` subcommand (`internal/cli/cmd/scenarios_run.go`) for running agent harness scenarios against a real Gateway/Operator. Supports mTLS and public URL modes, configurable L3 mode, ensemble size, consensus seeds, and output directory. Replaces the previous `agent-harness` command.
* **Frontend Demo** — New `demos/frontend/` demo with a frontend enrollment scenario (`internal/cli/cmd/demo_frontend.go`). Includes `compose.yml`, `app/index.html`, gateway/operator configs, and frontend doctrine.
* **Default TUI Launch** — Running `g8e` with no arguments now launches the Tactical Governance Console (TUI) via `runTUI` in `internal/cli/cmd/main.go`.
* **OpenAPI/Swagger Annotations** — Added Swagger annotations to gateway handlers across `auth_controller_session.go` (users, logout, session), `gateway_http_sse.go` (SSE push, events, stream), `governance_envelope.go` (envelope submission), and `passkey_service_approvals.go` (approval challenge, verify, list). Swagger JSON/YAML regenerated in `internal/services/gateway/docs/`.
* **`docs/guides/gui_enrollment.md`** — New guide documenting the `g8e gui` command for external frontend enrollment.
* **`docs/architecture/scripts.md`** — New architecture document (added in v1.3.11, updated in this release with consolidated web-cert script references).

## Changed

* **`operator run` → `operator start`** — Renamed `operatorRunCmd` to `operatorStartCmd` in `internal/cli/cmd/operator.go`. The command `Use` changed from `run` to `start` with updated short/long descriptions. Updated `docs/guides/build_operator.md` to reflect the new command name.
* **L5 Actuator Refactor** — `internal/services/governance/l5_actuator.go`: Removed direct `ExecutionService` and `context.Context` fields from `L5Actuator` struct. The actuator now relies solely on the `ExecutionHandler` interface. Extracted `Rehydratable` interface (previously an anonymous interface check). Extracted `buildReceiptRecord` helper to eliminate duplicated record construction between `LogReceipt` and `logReceiptDocument`. `initializeGovernance` in `internal/services/pubsub/pubsub_commands.go` updated to drop the `serviceCtx` parameter.
* **Consolidated Web-Cert Trust Scripts** — Replaced three separate bootstrap CA script endpoints (`/bootstrap-ca`, `/bootstrap-ca-macos`, `/bootstrap-ca.ps1`) with two consolidated endpoints (`/web-cert.sh`, `/web-cert.ps1`) in `internal/constants/api_paths.go` and `internal/services/gateway/pki_controller.go`. The Linux/macOS script is now combined into a single `web-cert.sh`. Trust scripts no longer download the g8e binary — they only install the CA bundle. Route auth registry in `gateway_auth.go` updated accordingly.
* **`agent-harness` Channel → `scenarios` Channel** — Pub/Sub mutation channel prefix renamed from `agent-harness:*` to `scenarios:*` in `docs/guides/build_gateway.md` documentation.
* **Web Session Cookie Name** — Cookie value renamed from `g8e_session` to `web_session` to properly qualify the session type. Updated `docs/release_notes/v1.2.x/v1.2.4.md` to document this change.
* **SSE Architecture Doc Simplified** — `docs/architecture/sse.md` significantly rewritten and simplified (349 lines reduced).
* **`build_agentic_system.md` Merged into `build_apps.md`** — Deleted `docs/guides/build_agentic_system.md` (693 lines) and merged its content into `docs/guides/build_apps.md`. Updated `docs/release_notes/v1.2.x/v1.2.3.md` to note the merge.
* **`lovable-deployment.md` Merged into `lovable.md`** — Consolidated Lovable deployment guide content into `docs/guides/lovable.md`.
* **Approval Handler Auth Check Ordering** — In `internal/services/gateway/passkey_service_approvals.go`, the user ID auth check in `handleApprovalAction` is now performed before path parsing, preventing unauthenticated requests from reaching path segmentation logic.
* **Protocol Python Version** — Updated `protocol/python/pyproject.toml` and `protocol/python/g8e/__init__.py` to v1.4.0.

## Removed

* **`docs/guides/build_agentic_system.md`** — Merged into `docs/guides/build_apps.md`.
* **`docs/guides/lovable-deployment.md`** — Merged into `docs/guides/lovable.md`.
* **macOS Bootstrap CA Endpoint** — The separate `/bootstrap-ca-macos` endpoint and its handler `handleTrustScriptMacos` are removed. Linux and macOS share the combined `/web-cert.sh` endpoint.
* **Binary Download from Trust Scripts** — Trust scripts no longer download the g8e binary. They install only the CA bundle, reducing the attack surface and simplifying the remote workstation setup flow.

## Fixed

* **Windows Build** — Fixed Makefile and `.gitattributes` for Windows compatibility. Added `.gitattributes` entries for line-ending handling and updated `Makefile` build flags. Fixed `protocol/go.mod` dependency issue that broke Windows builds.
* **Test Reliability** — Fixed multiple test files for consistent behavior: `approval_sse.go` (SSE client connection handling), `approve_api_test.go` (test assertions), `sse/client.go` (connection error handling), `keystore_edge_test.go`, `csvwriter_test.go`, `run_integration_test.go`, `ledger_bootstrap_test.go`, `replay_store_test.go`, `suspended_transaction_store_test.go`, `factory_test.go`.

## Security

* **Approval Handler Auth Ordering** — Moved user ID authentication check before path parsing in `handleApprovalAction`, ensuring unauthenticated requests are rejected before any request path processing occurs.
