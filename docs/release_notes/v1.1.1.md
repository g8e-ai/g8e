## [1.1.1] - 2026-06-15

### Overview

v1.1.1 is a maintenance and stability release focused on improving test coverage, fixing deployment issues, and refining core services. Significant work was done to increase gateway test coverage to over 65%, alongside critical bug fixes in docker deployments, ledger wiring, and heartbeat mechanisms.

### Changed

* **Test Coverage Improvement** — Significantly increased gateway test coverage to over 65% in `test/a2a_gateway_test.go` and related integration tests, improving reliability and future maintainability.
* **Test Infrastructure Refactoring** — Refactored `testbackend` in `test/integration_helper.go` and improved unit tests for various scenarios to provide more robust testing foundations.
* **Scrubbing Logic Enhancement** — Improved scrubbing logic in `internal/services/scrubber/` for better data sanitization and security.
* **Emulator Documentation** — Updated emulator documentation in `docs/guides/emulator.md` to provide clearer guidance for developers.

### Fixed

* **Docker Deployment Fixes** — Resolved issues in docker deployments within `docker-compose.yml` and `Dockerfile.operator` to ensure smoother orchestration and setup.
* **Ledger Wiring** — Fixed wiring issues in the ledger service within `internal/services/ledger/` for improved data consistency.
* **Heartbeat Test Stability** — Fixed flaky heartbeat tests in `internal/services/mcp/` to ensure reliable CI/CD pipelines.

### Verification

```bash
make build
./g8e --version

make test-integration
```
