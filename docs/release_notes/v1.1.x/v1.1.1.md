## [1.1.1] - 2026-06-15

### Overview

v1.1.1 is a comprehensive maintenance and stability release that significantly hardens the g8e platform. This release features a major architectural decomposition of the gateway's authentication controller, a systematic refactoring of MCP tools for improved testability, and a massive push for integration test coverage. Additionally, this release introduces full OpenAPI/Swagger documentation for the gateway and resolves critical data races in core services.

### Added

* **OpenAPI/Swagger Documentation** — Added complete Swagger and OpenAPI specifications in `internal/services/gateway/docs/` for all gateway REST endpoints, improving developer integration.
* **Docker E2E Test Harness** — Introduced a new, robust end-to-end testing harness in `test/e2e/harness.go` with dedicated Docker fixtures for orchestrated environment verification.
* **New Test Scenarios** — Added comprehensive concurrency and scenario-based tests in `test/scenario/` to ensure platform stability under high load.

### Changed

* **Auth Controller Decomposition** — Refactored the monolithic `AuthController` in `internal/services/gateway/` into specialized components (`approvals`, `bootstrap`, `passkey`, `session`) to improve maintainability and security isolation.
* **MCP Tool Testability Refactor** — Systematic refactoring of native MCP tools (including `db_index_triage`, `sys_oom_detect`, `net_dns_resolve`, and `sys_time_clock`) to support dependency injection, allowing for high-fidelity unit testing without side effects.
* **Test Coverage Improvement** — Significantly increased gateway test coverage to over 65% in `test/a2a_gateway_test.go` and related integration suites, ensuring long-term stability.
* **Documentation Overhaul** — Updated and refined almost all user guides in `docs/guides/`, including air-gap deployments, Docker orchestration, and operator-to-gateway connectivity.
* **PubSub Command Expansion** — Expanded internal pubsub command handlers in `internal/services/pubsub/pubsub_commands.go` for more robust service orchestration.
* **Scrubbing Logic Enhancement** — Improved data sanitization logic in `internal/services/scrubber/` for better security and privacy.

### Fixed

* **Execution Service Race Conditions** — Resolved critical data races in `internal/services/execution/` that could occur during concurrent command execution.
* **Gateway Data Races** — Fixed multiple race conditions in the gateway core to ensure deterministic behavior.
* **Docker Deployment Reliability** — Resolved orchestration issues in `docker-compose.yml` and `Dockerfile.operator` to ensure smoother multi-service setups.
* **Heartbeat Test Stability** — Eliminated flakiness in MCP heartbeat tests in `internal/services/mcp/` for more reliable CI/CD pipelines.
* **Protocol Generation** — Fixed `make proto` command and improved protocol buffer generation across the codebase.

### Removed

* **Deprecated Invitation Service** — Cleaned up the legacy invitation service in `internal/services/gateway/` as part of the transition to the new registration flow.
* **Database Migration Cruft** — Removed obsolete database migration logic and unused SQL utilities to reduce technical debt.

