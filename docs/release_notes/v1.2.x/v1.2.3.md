## [1.2.3] - 2026-06-26

### Overview

v1.2.3 is a passkey architecture consolidation and dependency reduction release. This version moves all 15 passkey HTTP handlers from `AuthController` into `PasskeyService` with a typed config system, eliminates the `swaggo/swag` and `google/uuid` dependencies, adds a token bucket rate limiter, and introduces a comprehensive guide for building g8e-compliant agentic systems. The release also renames passkey routes to descriptive `bootstrap/*` and `console/*` paths with deprecated aliases for backward compatibility.

### Added

* **PasskeyService HTTP Layer** — Added `passkey_service_http.go` with four factory methods (`RegisterChallenge`, `RegisterVerify`, `AuthenticateChallenge`, `AuthenticateVerify`) using a typed `passkeyHandlerConfig` struct, plus three direct handler methods (`ListCredentials`, `RevokeCredential`, `CLIStatus`). The factory methods accept a config that encodes the auth source (mTLS, JWT, CLI bootstrap, browser bootstrap), first-credential enforcement, session-user binding, and web session/cookie creation flags. This eliminates 15 copy-pasted handlers from `AuthController` and removes fragile `strings.Contains(r.URL.Path, "/jit-")` URL sniffing in favor of config-driven control flow set at route mount time.

* **Passkey Route Renames** — Renamed passkey routes to descriptive `bootstrap/*` and `console/*` paths:
  - `cli-register/*` → `bootstrap/register/*`
  - `cli-browser-register/*` → `console/register/*`
  - `browser/authenticate/*` → `console/authenticate/*`
  - `cli/authenticate/*` → `bootstrap/authenticate/*`
  
  Old paths retained as deprecated aliases with structured `Warn`-level deprecation logging (including `old_path`, `new_path`, `method`, `remote_addr`) for one minor version. New API path constants added to `internal/constants/api_paths.go` and mirrored in `protocol/constants/api_paths.json`.

* **Token Bucket Rate Limiter** — Added `internal/services/gateway/token_bucket.go` with a thread-safe token bucket implementation for rate limiting gateway endpoints.

* **Passkey Credential Validation** — Added `PasskeyCredential.Validate()` method and `encodeCredID`/`decodeCredID` helpers in `internal/models/auth.go` with comprehensive encoding tests in `passkey_encoding_test.go`. Ensures credential IDs are safely encoded/decoded between storage and WebAuthn library representations.

* **Build Agentic System Guide** — Added `docs/guides/build_agentic_system.md`, a 727-line comprehensive guide for building g8e-compliant agentic systems. Covers agent harness setup, governance envelope submission, L1-L5 pipeline, and demo scenarios.

* **Demos CLI Command** — Added `g8e demos` command with subcommands for listing available demos and running demo scenarios. Includes `demos_test.go` for command coverage.

* **Gateway Startup Output** — Improved gateway startup output in `internal/cli/cmd/gateway.go` with clear connection information, listening addresses, and status display. Added config loading improvements in `internal/cli/config/config.go`.

* **Passkey Service HTTP Tests** — Added `passkey_service_http_test.go` (408 lines) with table-driven config matrix tests covering all four factory methods (`RegisterChallenge`, `RegisterVerify`, `AuthenticateChallenge`, `AuthenticateVerify`) and three direct handlers (`ListCredentials`, `RevokeCredential`, `CLIStatus`). Tests verify auth source differentiation, first-credential enforcement, session-user binding, and web session/cookie creation behavior.

### Changed

* **PasskeyService Constructor** — Updated `NewPasskeyService` signature to accept `userSvc *UserService`, `webSessionSvc *WebSessionService`, `responder *response.Writer`, and `maxPayload int64` dependencies. This enables the service to own its complete HTTP layer without delegating to `AuthController` for body reading, response writing, or session/user lookups. All 6 call sites updated.

* **Router Rewired** — All passkey route registrations in `gateway_http_router.go` now reference `h.passkey.*` factory methods with typed config constants (`mtlsCfg`, `jitCfg`, `cliBootstrapRegisterCfg`, `cliBootstrapAuthCfg`, `browserBootstrapRegisterCfg`, `browserBootstrapAuthCfg`) instead of `h.authController.handleAuthPasskey*` handlers. Config is set at route mount time, replacing runtime URL path inspection.

* **PublicRouteRegistry Simplified** — Replaced 4 exact-path entries for browser passkey endpoints with 2 prefix entries (`AuthPasskeysBootstrapPrefix` and `AuthPasskeysConsolePrefix`). Deprecated alias exact paths maintained during transition. Excluded prefixes updated to protect mTLS-only sub-paths.

* **CLI Client Updated** — `PerformNativeWindowsAuth` in `internal/cli/auth/client.go` now uses `constants.APIPaths.AuthPasskeysBootstrapAuthenticateChallenge` and `AuthPasskeysBootstrapAuthenticateVerify` constants instead of hardcoded path strings.

* **Network Identity** — Enhanced `internal/services/network/identity.go` with improved identity resolution for edge deployment scenarios.

* **PKI Controller** — Improved `internal/services/gateway/pki_controller.go` with better error handling and response structure for CSR signing.

### Fixed

* **CLI Passkey Status** — Fixed CLI reporting "No passkey registered" for users who enrolled via the browser console. The CLI previously queried a `WebSessionAuth`-protected endpoint using mTLS, received 401, and silently mapped it to "no passkey" — triggering unwanted re-enrollment. CLI now uses dedicated mTLS endpoint `/api/v1/auth/passkeys/cli/status` with explicit error classification: 200+empty → no passkey, 200+non-empty → has passkey, 401/403 → auth error, 5xx/transport → network error.

* **DoW Simulator** — Fixed `demos/dow/dow_simulator.py` timing and state management issues that caused incorrect scenario execution.

* **Agent Harness Client** — Fixed API path references in `internal/tools/agent_harness/client/client.go` and improved test reliability in `client_test.go`.

### Removed

* **`auth_controller_passkey.go`** — Deleted entirely (358 lines). All 7 passkey handlers moved to `PasskeyService`.

* **`auth_controller_bootstrap.go` passkey handlers** — Stripped 8 passkey handlers (535 lines). Non-passkey bootstrap handlers (`handleLocalBootstrapWithURL`, `handleCLIEnrollment`, `handleDeviceEnrollment`, `handleBootstrapStatus`) retained.

* **`auth_controller_passkey_test.go`** — Deleted (467 lines). Replaced by `passkey_service_http_test.go` with config matrix tests.

* **`auth_controller_bootstrap_test.go` passkey tests** — Stripped passkey test functions (506 lines). Non-passkey tests retained.

* **Swagger dependency eliminated** — Removed `github.com/swaggo/swag` and `github.com/swaggo/http-swagger` imports from `internal/services/gateway/docs/docs.go`, reducing 661 lines of auto-generated swagger registration code. Swagger UI now served via native embedded HTML handler from CDN.

* **`google/uuid` dependency** — Replaced with native `internal/uuid` package using `crypto/rand` for UUIDv4 generation, eliminating the external dependency.
