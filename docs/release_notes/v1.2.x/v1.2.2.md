## [1.2.2] - 2026-06-25

### Overview

v1.2.2 is a security hardening, testability, and documentation consolidation release. This version introduces a `PrivilegedRouteRegistry` to prevent app certificates from submitting governance envelopes, adds a private IP allowlist for MCP HTTP probing in disconnected edge environments, and improves shell safety by moving `curl`/`wget` to command-name-based blocking. The release also refactors CLI commands for dependency injection testability, consolidates three architecture docs into two, and adds ~2000 lines of new unit test coverage.

### Added

* **PrivilegedRouteRegistry** — New gateway auth component that blocks app certificates (issued via `/api/v1/pki/apps/enroll`) from submitting governance envelopes via `POST /api/v1/governance/envelopes`. Only operator and CLI mTLS certificates may submit envelopes. The registry uses a prefix-based check in `handleAppAuth` to reject app-cert requests to privileged endpoints with a 403 Forbidden.

* **Private IP Allowlist for MCP** — Added `SetPrivateIPAllowlist` and `isIPAllowed` in `internal/services/mcp/validation.go` with a thread-safe (`sync.RWMutex`) CIDR allowlist. MCP HTTP probe (`net_http_probe.go`) and request validation (`validateHTTPRequestURL`) now permit configured private/loopback addresses, supporting disconnected edge scenarios where internal endpoints must be reachable. Pass `nil` or empty slice to reset to default (no private IPs allowed).

* **PKI CSR Sign Endpoint** — Registered `constants.APIPaths.PKICSRSign` route in the HTTP router for headless CSR signing, complementing the existing device enrollment path.

* **DoW Demo: Real Governance Envelope Submission** — Converted the DoW tactical edge demo Scenario 1 from scripted theater into a genuine end-to-end exercise. The `agent-sigint` container is now a real g8e binary that submits `GovernanceEnvelope`-wrapped `run_shell_command` tool calls through the full L1/L2/L5 pipeline. Added `dow-cross-cue` and `dow-bft-veto` harness scenarios. Added mock gimbal HTTP server (`gimbal.py`), `slew.sh`, `inspect_pnt.py`, `inspect_rf.py`, and `verify_slews.py` demo artifacts for actuation and verification.

* **Operator Cert Sharing for Agent Containers** — Agent containers in demos can now share the operator's enrolled mTLS credentials via a read-only volume mount (`operator_state:/root/.g8e:ro`), eliminating the need for a separate enrollment init container. The agent uses the operator's cert/key/CA bundle directly, and the gateway validates the operator session from the certificate's SPIFFE URI SAN.

* **Offline Session Discovery** — `DiscoverOperator` in the agent harness now parses the operator's PEM certificate SPIFFE URI SAN to extract operator ID and session ID, enabling headless session recovery in disconnected environments without network calls. The SPIFFE URI format is `spiffe://g8e.local/operator/<user_id>/<operator_id>/<operator_session_id>`.

* **Comprehensive Test Coverage** — Added ~2000 lines of unit tests across the codebase:
  - `approve_api_test.go`, `approve_test.go`, `approve_integration_test.go` — CLI approval command tests with mock API clients
  - `audit_test.go` — Audit command tests with config injection
  - `gateway_extra_test.go`, `operator_extra_test.go` — Gateway and operator command tests
  - `report_test.go`, `test_test.go` — Report and test command tests
  - `csvwriter_test.go`, `rows_test.go` — Reporting service unit tests
  - `validation_test.go` — MCP validation tests including private IP allowlist
  - `gateway_auth_registry_test.go` — Auth registry tests including privileged route blocking
  - `dow_cross_cue_test.go` — Agent harness cross-cue scenario tests
  - `agent_harness_extra_test.go` — Harness command tests with io.Writer capture

* **Architecture Documentation Consolidation** — Merged three standalone architecture documents into two consolidated references:
  - `docs/architecture/binding.md` → absorbed into `docs/architecture/governance.md` and `docs/architecture/auth.md`
  - `docs/architecture/postures.md` → absorbed into `docs/architecture/governance.md`
  - `docs/architecture/transaction-process.md` → absorbed into `docs/architecture/governance.md`
  - Added comprehensive Session & Identity Binding section (§7) to `auth.md` covering web↔operator binding, CLI cert binding, persona binding, PKI credential binding, and envelope binding
  - Added `docs/media/jit-mcp-with-receipts.png` diagram

### Changed

* **Agent Harness Refactored** — Harness now uses `io.Writer` for all output (enabling test capture), returns errors instead of calling `os.Exit(1)`, and `DiscoverOperator` returns both operator ID and session ID. `GovKit` struct updated with `OperatorSessionID` field for proper envelope session binding.

* **CLI Dependency Injection** — Refactored `approve`, `audit`, and `data` CLI commands to accept injectable config loader (`func(string) (*config.Config, error)`) and API client factory (`func(*config.Config) (apiClient, error)`) functions, enabling unit testing without real network or config dependencies. Each command now has a `*WithConfig` variant for testing.

* **Shell Safety: curl/wget Blocking** — Moved `curl` and `wget` from `DangerousPatterns` (pattern-matched in command strings, easily bypassed via aliases or path variations) to `DangerousCommands` (command-name-matched at the token level) in `internal/constants/shell.go` for more reliable enforcement.

* **DoW Demo: Python Extraction** — Extracted inline Python scripts from demo `compose.yml` into standalone files under `demos/dow/` for better maintainability and testability.

### Fixed

* **App Cert Governance Envelope Submission** — Fixed a security issue where app certificates could submit governance envelopes via `POST /api/v1/governance/envelopes`. Now blocked by `PrivilegedRouteRegistry` which checks `handleAppAuth` and returns 403 Forbidden for app-cert requests to privileged endpoints.

* **MCP HTTP Probe Private IP Blocking** — Fixed unconditional blocking of private/loopback addresses in MCP HTTP probe (`net_http_probe.go`) and request validation (`validateHTTPRequestURL`), preventing legitimate internal endpoint access in edge deployments. Now respects the configurable allowlist.

* **OperatorSessionId Propagation** — Fixed `SubmitMaximal` in the agent harness not setting `OperatorSessionId` on `GovernanceEnvelope`, causing L5 actuator receipt recording to fail with a FOREIGN KEY constraint. All call sites now correctly pass the session ID.

* **Agent Harness API Path Hardcoding** — All five harness client methods (`DiscoverOperator`, `AuditReceipts`, `ExportReceipts`, `RegisterSigner`, `Approve`) now use `constants.APIPaths.*` constants instead of hardcoded path strings. Unit test path assertions also updated to use constants.
