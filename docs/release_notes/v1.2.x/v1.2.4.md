## [1.2.4] - 2026-06-26

### Overview

v1.2.4 is a console UX and passkey bootstrap refinement release. This version adds a browser-facing SSE audit stream to the console via the unified `/api/v1/sse/stream` endpoint, introduces automatic user creation during browser passkey bootstrap, hardens Windows Hello WebAuthn with HRESULT mapping and input validation, replaces hardcoded cookie name strings with a shared constant, and regenerates the Swagger/OpenAPI specification with full passkey and session management annotations.

### Added

* **Unified SSE Streaming for Browser** — The console SPA now connects to `/api/v1/sse/stream` (mTLS authenticated) with `web_session_id` as a query parameter, using the same endpoint as CLI and dashboard clients. No separate browser streaming endpoint, no mTLS bypass, no cookie-based auth for SSE. Includes 30-second heartbeat keepalive and back-pressure handling with event dropping when the client buffer is full.
* **Automatic User Creation on Browser Bootstrap** — Added `CreateUser` and `HasAnyUsers` methods to the `userStore` interface with a `createUserOnBootstrap` config flag in `passkeyHandlerConfig`. Browser passkey bootstrap now auto-creates a user when no users exist, enabling true zero-config first-run enrollment. The `dbUserStore` implementation uses `internal/uuid` for user and WebAuthn user ID generation.
* **Windows Hello HRESULT Mapping** — Added `mapWebAuthnHRESULT` function to translate Windows WebAuthn HRESULT codes to descriptive error messages. New error constants: `ErrWindowsHelloUserCancelled`, `ErrWindowsHelloDeviceNotFound`, `ErrWindowsHelloDeviceNotReady`, `ErrWindowsHelloNotSupported`, `ErrWindowsHelloTimeout`, `ErrWindowsHelloInvalidUserID`, `ErrWindowsHelloEmptyInput`, `ErrWindowsHelloResponseTooLarge`.
* **Windows Hello Input Validation** — Added input validation for challenge emptiness, user ID size (16-byte GUID for WebAuthn v4 compliance), and response pointer/size bounds checking before extraction, preventing potential memory safety issues with malformed WebAuthn responses.
* **Windows Crypto Mock Tests** — Added `internal/cli/auth/windows_crypto_mock_test.go` (390 lines) with comprehensive unit tests for Windows Hello WebAuthn registration and authentication flows using mock syscall interfaces.
* **Swagger/OpenAPI Regeneration** — Regenerated `swagger.json` (776 lines) and `swagger.yaml` (581 lines) with full annotations for all passkey endpoints (`RegisterChallenge`, `RegisterVerify`, `AuthenticateChallenge`, `AuthenticateVerify`, `ListCredentials`, `RevokeCredential`, `CLIStatus`), audit stream, and session management routes.
* **L3 Notary Tests** — Added `internal/services/governance/l3_notary_test.go` (135 lines) with comprehensive tests for L3 notary proof verification.
* **Passkey Register Challenge Response** — Added `user_id` field to `PasskeyRegisterChallengeResponse` model for client-side user tracking during bootstrap flows.
* **Passkey Route Alias Constants** — Added `AuthPasskeysCLIRegisterChallenge/Verify` and `AuthPasskeysCLIAuthenticateChallenge/Verify` constants for deprecated route aliases.

### Changed

* **WebSession Cookie Name Constant** — Replaced all hardcoded `"g8e_session"` string literals with `constants.WebSessionCookieName` across `auth_controller_session.go` (4 sites), `passkey_service_http.go` (2 sites), and `gateway_auth.go` (1 site). New constant defined in `internal/constants/auth.go`.
* **Passkey Bootstrap CLI Path** — Updated `passkey_bootstrap.go` to use `constants.APIPaths.AuthPasskeysConsoleRegisterVerify` instead of hardcoded `/api/v1/auth/passkeys/cli-browser-register/verify` path string.
* **Gateway Serve Command Hidden** — Marked `g8e gateway serve` CLI command as `Hidden: true` since it is an internal re-exec target for `gw start`, not a user-facing command.
* **Encode Challenge Helper** — Extracted `encodeChallenge` helper in `passkey_service.go` for semantic clarity over inline `base64.RawURLEncoding.EncodeToString` calls in `GenerateApprovalChallenge` and `VerifyL3Proof`.
* **Deprecated Passkey Route Aliases** — Added `AuthPasskeysCLIRegisterChallenge`, `AuthPasskeysCLIRegisterVerify`, `AuthPasskeysCLIAuthenticateChallenge`, and `AuthPasskeysCLIAuthenticateVerify` to `PublicRouteRegistry` deprecated alias list for backward compatibility during the `cli-*` to `bootstrap/*`/`console/*` route transition.
* **Console SPA Enhancements** — Updated console `index.html` (276 lines changed) with improved audit stream integration, session management, and error handling.

### Removed

* **Browser SSE Web Handler** — Deleted `internal/services/gateway/gateway_http_sse_web.go` and the `/api/v1/audit/stream` endpoint. Browser SSE streaming is now handled by the unified `/api/v1/sse/stream` endpoint with mTLS authentication.
* **Terminal Linux Package** — Deleted `internal/cli/serve/terminal_linux.go` and `terminal_linux_test.go` (262 lines). The obfuscated input reader was unused after the serve command was simplified.
