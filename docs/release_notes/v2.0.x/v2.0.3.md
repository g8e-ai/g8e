## [2.0.3] - 2026-08-27

### Overview

v2.0.3 implements the ModeDeps refactor, modeling service mode (gateway vs outbound) and posture (doctrine, consensus, notary) as first-class design concerns. By introducing mode-specific dependency types (`GatewayModeDeps` and `OutboundModeDeps` embedding `GovernanceCoreDeps`) and an inverted lifecycle construction order (C2), the compiler statically proves which dependencies exist per mode. This eliminates lazy forwarding adapters, post-construction setter mutators, and call-site nil guards across the codebase.

### Changed

* **ModeDeps dependency construction model** — Replaced the shared `pubsub.GovernanceDeps` struct with `pubsub.GovernanceCoreDeps` embedded by mode-specific `GatewayModeDeps` and `OutboundModeDeps` in `internal/services/pubsub/mode_deps.go`. `GatewayModeDeps` adds gateway-specific dependencies (`GovernedDocStore`, `ConsensusPolicyStore`, `FieldReader`, `Consensus`, `PlatformEnrollmentDeps`, `Posture`), while `OutboundModeDeps` embeds only `GovernanceCoreDeps`. Both constructors (`NewGatewayModeDeps` and `NewOutboundModeDeps`) validate required fields and reject nil dependencies with typed errors at construction time.
* **C2 inverted construction order in Gateway boot** — Restructured gateway initialization to open the database and typed stores, bootstrap consensus, construct `OperatorPubSubService`, initialize `PlatformEnrollmentService`, construct `mcp.GatewayService` with concrete dependencies, and wire the atomic egress setter (`SetMCPGateway`) before assembling `GatewayModeService` and initializing the HTTP handler.
* **Posture-gated route registration (503 to 404 transition)** — Route registration in `internal/services/gateway/gateway_http_router.go` posture-gates `/consensus/deliberate`, skipping registration when `Posture == PostureDoctrine`. Requests to `/consensus/deliberate` in doctrine posture now return 404 (Not Found) rather than 503 (Service Unavailable). `GovernanceController` now holds a direct pointer `*consensus.ConsensusService` instead of an atomic pointer wrapper.
* **Concrete injection and setter elimination** — Removed `SetAuditLogger` and `SetL2ConsensusDeliberator` from `mcp.GatewayService`, wiring both dependencies directly at construction in `mcp.Dependencies`. Removed `SetConsensusService` and `LoadConsensusService` from `GatewayModeService`. Retained `SetMCPGateway` on `OperatorPubSubService` as the single atomic-backed egress setter for two-phase dispatch.
* **Platform enrollment mode typing** — `PlatformEnrollmentService` accepts concrete `governance.EnvelopeProcessor` (`*pubsub.OperatorPubSubService`) rather than an adapter. `PlatformEnrollmentHandler` is a required field in gateway mode and absent in outbound mode, eliminating call-site nil-checks in `ExecuteVerifiedTransaction`.

### Removed

* **Lazy forwarding adapters** — Deleted `GatewayEnvProcAdapter` and `GatewaySessionValidatorAdapter` from `internal/services/pubsub/pubsub_commands.go`.
* **Obsolete adapter race tests** — Deleted `internal/services/pubsub/gateway_adapter_race_test.go` and removed obsolete setter race tests.
* **`demos/frontend/` demo environment** — Removed the minimal frontend enrollment smoke test demo in its entirety: the `demos/frontend/` directory (`README.md`, `app/index.html`, `compose.yml`, `config/gateway.yml`, `config/operator.yml`, `doctrine/frontend_doctrine.json`), the `g8e demos frontend` CLI command (`internal/cli/cmd/demo_frontend.go` and its routing test), the `DemosOrgFrontend` constant, the `frontend` scenario in `g8e demos scenarios`, and the frontend port/container mappings in `internal/cli/cmd/demos.go`. The real product UI is the `dashboard/` (g8ed) component; the standalone enrollment smoke test is no longer shipped as a demo. Documentation references to `demos/frontend/` were removed from `docs/architecture/dashboard.md`, `docs/architecture/overview.md`, `docs/guides/air_gap.md`, `docs/guides/docker_gateway.md`, and `protocol/docs/constants.md`.

### Added

* **Operator Binary Download console section** — Added an "Operator Binary Download" card to the gateway console SPA (`internal/services/gateway/console/static/index.html`) that renders direct download links for each supported platform binary (Linux amd64/arm64/386, macOS arm64/amd64, Windows amd64/arm64) under the canonical `/.well-known/g8e/bin/` path, with copy-to-clipboard command strings for workstation installation. Backed by `internal/services/gateway/console/operator_binary_download_ui_test.go` asserting the section, binary filenames, and download paths are present.
* **Egress setter concurrency test** — Added `TestOperatorPubSubService_SetMCPGateway_RaceWithEgressCall` in `internal/services/pubsub/pubsub_commands_test.go` to verify thread safety of the atomic egress setter under concurrent dispatch.
* **AST lint guards** — Added `internal/services/pubsub/adapter_guard_test.go` (`TestPubSub_NoDeletedAdapters`), `internal/services/pubsub/platform_enrollment_guard_test.go` (`TestExecuteVerifiedTransaction_NoPlatformEnrollmentNilGuards`), and `internal/services/gateway/gateway_setter_guard_test.go` (`TestGatewayModeService_NoDeletedSetters`) to prevent reintroduction of deleted adapters, setters, and nil guards.

### Fixed

* **Compliance command context propagation** — Hoisted `ctx := cmd.Context()` initialization to the top of the `compliance generate` and `compliance ksi` command handlers in `internal/cli/cmd/compliance.go`, ensuring the context is available before `fileSvcFactory` is invoked and is consistently passed to `evaluateKSIs`, `saveKSIHistorySnapshot`, and `MkdirAll` rather than re-deriving it mid-handler.
* **Auth middleware nil-guard in public router** — `buildPublicRouter` in `internal/services/gateway/gateway_http_router.go` now guards `authMiddleware` against nil before wrapping the mux and the `PubSubStream` route, allowing the router to assemble correctly when auth middleware is not configured (e.g., outbound mode).

### Tests

* **`internal/services/pubsub/mode_deps_test.go`** — Unit tests verifying constructor validation and nil rejection for `NewGatewayModeDeps` and `NewOutboundModeDeps`.
* **`internal/services/pubsub/pubsub_commands_test.go`** — Updated `TestCommandServiceConfig_NoGatewayFields` using reflection to enforce that `OutboundModeDeps` contains no gateway-only fields.
