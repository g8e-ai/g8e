## [2.0.4] - 2026-08-27

### Overview

v2.0.4 is a usability and reliability patch release focused on headless deployment, CLI data access, operator enrollment, and file-mutation evidence. It adds a repeatable end-to-end UX smoke-test runbook and corrects several paths that could make working features appear unavailable or leave incomplete audit evidence.

### Added

* **Headless end-to-end UX smoke test** — Added `docs/guides/ux_smoke_test.md`, a CLI-only runbook for bootstrapping the Docker stack, enrolling an owner without a browser, approving platform workloads, exercising the ensemble scenario, inspecting receipts, generating evidence reports, and verifying the binary discovery endpoint.
* **CLI user listing** — Added `GET /api/v1/users` handling to the users controller and exposed user listing through `g8e gw data users`.
* **Structured audit-event display** — Updated `g8e gw data audit list` to use the audit-events GET endpoint and render typed event summaries with counts and command details.

### Changed

* **Operator endpoint handling** — Operator trust-bundle and platform-enrollment requests now preserve endpoint URLs and explicit ports while defaulting plain hostnames and IP addresses to the operator HTTP port.
* **Pending enrollment filtering** — Platform enrollment discovery now returns only non-expired requests in the pending state, excluding denied, completed, and other terminal requests.
* **Documentation alignment** — Updated user-facing protocol package version callouts to v2.0.4 and removed the stale standalone frontend demo reference from the getting-started guide.

### Fixed

* **Ledger-backed file mutation capture** — File writes, creates, and deletes now begin a ledger two-phase commit before execution and complete it after successful execution, preserving before/after hashes and diff statistics for audit records.
* **File diff vault persistence** — Successful file mutations now write non-empty ledger diffs through the typed vault diff API, restoring evidence capture for file-edit receipts.
* **CLI output routing** — The root command explicitly routes Cobra output and errors to standard output and standard error so version and help output are visible in direct CLI usage.

### Tests

* Added operator endpoint URL coverage for schemes, explicit ports, and default-port behavior.
* Updated file-operation tests for ledger two-phase commit and vault diff persistence.
* Expanded user-controller, operator, and CLI data tests for the corrected behavior.
