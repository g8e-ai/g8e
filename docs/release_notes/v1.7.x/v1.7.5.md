## [1.7.5] - 2026-08-16

### Overview

Code quality, fail-closed wiring, and internal domain decoupling for v1.7.5. This release centralizes the `mcp stdio` credential constants, makes the audit store a hard dependency of the MCP gateway, decouples passkey proof verification from the governance L3 notary interface, and replaces unsafe late-bound `**T` pointers with `atomic.Pointer` for the gateway consensus service. It also narrows the audit HTTP response payloads to typed models and adds a typed `ToolArgs` layer to the agent harness client.

### Changed

* **`mcp stdio` credentials and flags are centralized in `internal/constants/`** — `internal/cli/cmd/mcp.go` no longer defines local `envG8EClientCert` or `flagClientCert` string constants. The env-var keys now live in `constants.EnvVar.ClientCert`, `ClientKey`, `CABundle`, `GatewayURL`, `AppID`, `AppCert`, and `AppKey`; the CLI flag name constants live in the new `constants.Flag` struct (`client-cert`, `client-key`, `ca-bundle`, `gateway-url`, `app-cert`, `app-key`). The `mcp stdio` user interface is unchanged; this is a code-quality consolidation.
* **Protocol `env_vars.json` `_go_const` values are normalized** — The Go constant references for the MCP stdio env vars now use `EnvVar.ClientCert` etc. instead of the old lowercase-prefixed Go variable names (`envG8EClientCert`). The JSON values (`G8E_CLIENT_CERT` etc.) and descriptions are unchanged.
* **`mcp.GatewayService` now requires `AuditStore`** — `NewGatewayService` returns `constants.ErrAuditStoreRequired` when `Dependencies.AuditStore` is nil. The `noopAuditEventRecorder` type is exported as `NoopAuditEventRecorder` for test-only construction; it is no longer used as a silent production default.
* **Audit store no longer uses an outbound adapter** — `storage.SQLAuditStore` now implements `governance.TransactionAuditStore.DocSet` directly. The `auditStoreTransactionStore` wrapper in `services/g8eo.go` is removed and outbound mode wires `SQLAuditStore` straight into `GovernanceDeps.TransactionAudit`.
* **Passkey domain is decoupled from the L3 notary interface** — `governance.PasskeyVerifier` is a new passkey-domain primitive; `PasskeyService.VerifyL3Proof` is renamed to `VerifyPasskeyProof`. `governance.passkeyL3Notary` adapts `PasskeyVerifier` to the `governance.L3Notary` interface so the passkey domain does not implement the governance interface directly. Public L3 behavior is unchanged.
* **Gateway consensus wiring uses `atomic.Pointer`** — `GatewayModeService.consensusSvc` is now an `atomic.Pointer[consensus.ConsensusService]` and `GovernanceController` captures `&ls.consensusSvc` (a `*atomic.Pointer`) instead of a raw `**consensus.ConsensusService`. `SetConsensusService` calls `Store`; request handlers call `Load`. This eliminates a data race under `-race` for a value written during boot and read on the request path.
* **Audit HTTP endpoints return typed models** — `AuditController` now builds `models.AuditEventsResponse`, `models.AuditSummaryResponse`, and `models.AuditReportResponse` for `/api/audit/events`, `/api/audit/summary`, and `/api/audit/report`. JSON wire keys remain the same; the `events` array in the report is now a list of JSON `RawMessage` objects produced by `toAuditEventRow`, which projects a narrower, stable set of fields.
* **Passkey orchestrator fail-closes on missing dependencies** — `NewPasskeyOrchestrator` now requires `SSEStore` and `PubSub` and returns `constants.ErrPasskeySSEDependenciesRequired` if either is nil. The no-op guards inside `EmitApprovalCompletedSSE` and `EmitPasskeyRegisteredSSE` are removed; the constructor handles the nil check.
* **L1 Doctrine is wired explicitly for outbound mode** — `pubsub.OperatorPubSubService.initializeGovernance` no longer defaults to `governance.NewL1Doctrine()` when `govDeps.Doctrine` is nil. Outbound mode now constructs the doctrine in `services/g8eo.go` and passes it into `GovernanceDeps`.
* **Command-layer coordinator factory is injected** — `internal/cli/cmd/auth.go` removes the `enrollCoordinatorFactory` package-level variable. `enrollCmdWithConfig` and `agentRunCmdWithConfig` accept an `enrollerFactory` parameter (mirroring `fileSvcFactory`) so tests inject a stub without mutating package state.
* **Agent harness protocol calls use typed args** — `internal/tools/agent_harness/client/protocols.go` introduces `ToolArgs`, `ShellCommandArgs`, `FSPathArgs`, `FSGrepArgs`, `FSWriteArgs`, and `ExecuteBashArgs` plus typed JSON-RPC params envelopes for `tools/call`, `resources/read`, `prompts/get`, and `a2a/call`. The wire shapes are unchanged; `map[string]any` is replaced by typed structs for internal clients.

### Added

* **`internal/constants/flags.go`** — New `Flag` struct with the six `mcp stdio` CLI flag name constants (`client-cert`, `client-key`, `ca-bundle`, `gateway-url`, `app-cert`, `app-key`).
* **`EnvVar` entries for MCP stdio credentials** — `ClientCert`, `ClientKey`, `CABundle`, `GatewayURL`, `AppID`, `AppCert`, and `AppKey` are added to `internal/constants/env_vars.go`.
* **`MCPTransportStdio` and Goose constants** — `MCPTransportStdio` (`"stdio"`), `MCPServerNameG8E` (`"g8e"`), `MCPG8EDescription` (`"g8e governance gateway"`), and `GooseExtTimeout` (`300`) in `internal/constants/mcp.go`.
* **New typed error constants** — `ErrAuditStoreRequired` and `ErrPasskeySSEDependenciesRequired` in `internal/constants/errors.go`.
* **Typed audit response models** — `internal/models/audit.go` adds `AuditEventRow`, `AuditEventsResponse`, `AuditSummaryResponse`, `AuditReportResponse`, and `AuditReportData`.
* **Race and harness test coverage** — `internal/services/pubsub/gateway_adapter_race_test.go` plus expanded pubsub, passkey, governance, and harness client tests.

### Fixed

* **Outbound audit store wiring** — `g8eo.go` now passes `governance.NewL1Doctrine()` and a `TransactionAuditStore` backed by `SQLAuditStore.DocSet` into the governance dependency struct, removing the hidden defaulting inside `pubsub_commands.go` and ensuring outbound L4Warden has a defined doctrine and audit path.

### Tests

* **`TestStoresDoesNotExportRawDB`** — Lint guard asserting `gateway.Stores` declares no `*sqliteutil.DB` field.
* **Passkey decoupling tests** — `passkey_service_l3notary_decoupling_test.go` and `l3_notary_test.go` cover the `PasskeyVerifier`/`passkeyL3Notary` adapter.
* **Audit store `DocSet` tests** — `transaction_audit_store_native_test.go` covers the new `SQLAuditStore.DocSet` path.
* **Atomic pointer consensus tests** — `governance_controller_test.go` covers the new `atomic.Pointer` consensus wiring.
* **Harness client and scenario tests** — `client/protocols_test.go` and scenario helpers are updated for the typed `ToolArgs` payloads.
* **Pubsub command and adapter race tests** — `pubsub_commands_test.go` and `gateway_adapter_race_test.go` cover the doctrine and concurrency paths.
