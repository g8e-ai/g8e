## [1.7.1] - 2026-08-10

### Overview

Gateway construction refactor. This release addresses three structural debts identified in the `docs/devs/codemap.md` review: (1) the `gateway.Stores` mega-struct Interface Segregation violation, (2) mode bifurcation propped up by two-phase construction and post-construction setters, and (3) the `HTTPHandler` mediator with 13 controllers plus direct accessors. All changes are internal construction/refactor only — no wire protocol, on-disk schema, or user-facing CLI behavior changes.

### Changed

* **`G8eoService.SetFileService` removed** — `fileSvc` is now a constructor argument on `NewG8eoService`. The post-construction setter (with its "Must be called before `Start()`" temporal coupling) is gone. All 4 call sites updated (`operator.go`, `g8eo_test.go`, `g8eo_lifecycle_test.go`, `g8eo_integration_test.go`). Affected files: `internal/services/g8eo.go`, `internal/cli/serve/operator.go`, `internal/services/g8eo_test.go`, `internal/services/g8eo_lifecycle_test.go`, `internal/services/g8eo_integration_test.go`, `internal/services/g8eo_edge_test.go`.

* **`mcp.GatewayService.SetRuntimeDeps` removed — single-phase construction** — `RuntimeDependencies` was merged into `Dependencies`. `SetRuntimeDeps`, `runtimeReady`, and `getRuntimeDeps` are removed. The `atomic.Pointer` field is gone. All 20 `getRuntimeDeps()` call sites in `gateway.go` now read struct fields directly. The `runtimeReady()` guards in `mcp_endpoint.go` and `gateway.go` are replaced with nil-checks on `g.envProc`. Affected files: `internal/services/mcp/gateway.go`, `internal/services/mcp/mcp_endpoint.go`, `internal/services/mcp/gateway_test.go`, `internal/services/mcp/gateway_integration_test.go`, `internal/services/mcp/cloud_metadata_test.go`, `internal/services/mcp/mcp_endpoint_test.go`, `internal/services/gateway/gateway_jwt_integration_test.go`, `internal/services/gateway/gateway_http_test.go`, `internal/services/gateway/auth_controller_test.go`.

* **Lazy forwarding adapters break `mcp.GatewayService` ↔ `OperatorPubSubService` cycle** — Two new adapter types in the `pubsub` package (`GatewayEnvProcAdapter`, `GatewaySessionValidatorAdapter`) implement `governance.EnvelopeProcessor` and `mcp.SessionValidator` respectively. They are pre-allocated in `GatewayModeService.build()`, passed to `NewGatewayService` as `EnvProc` / `SessionValidator`, and wired to the real `OperatorPubSubService` target by `NewGatewayOperatorPubSubService` via `adapter.SetTarget(rs)`. Before `SetTarget` is called, the adapters return `constants.ErrGatewayNotReady` (fail-closed). `GatewayCommandServiceConfig` gains `EnvProcAdapter` and `SessionValidatorAdapter` fields. `GatewayModeService` exposes `GetEnvProcAdapter()` and `GetSessionValidatorAdapter()` accessors. Affected files: `internal/services/pubsub/pubsub_commands.go`, `internal/services/gateway/gateway_service.go`, `internal/cli/serve/gateway.go`, `test/fixtures/gateway_fixture.go`.

* **Narrow setters replace `SetRuntimeDeps` for genuinely late-bound deps** — `SetAuditLogger` and `SetL2ConsensusDeliberator` are the only post-construction mutators on `mcp.GatewayService`. Unlike `SetRuntimeDeps`, there is no circular dependency, no `atomic.Pointer`, and no `runtimeReady()` guard — the fields are nil-checked at their call sites. `AuditStore` comes from `CommandServiceConfig.AuditStore` (configured in `serve/gateway.go` after `GatewayModeService` exists); the L2 deliberator requires `GatewayModeService` to exist for `ConsensusBootstrap`.

* **`gateway.Stores` no longer leaked past `CanonicalDBService`** — 11 narrow accessor methods added to `CanonicalDBService` in `gateway_db.go` (`GetDB`, `GetDocStore`, `GetAppPolicyStore`, `GetSignerStore`, `GetConsensusStore`, `GetStateRootSvc`, `GetReplayStore`, `GetKVStore`, `GetSSEStore`, `GetBlobStore`, `GetAuditStore`). `G8eoService.gatewayStores` field removed — outbound mode now uses `gatewayDB.GetKVStore()` / `GetAuditStore()` / `GetStateRootSvc()` accessors (3 of 11 stores). `GatewayModeService.stores` field and `GetStores()` method removed — replaced with 7 individual store fields (`docStore`, `consensusStore`, `signerStore`, `auditStore`, `stateRootSvc`, `kvStore`, `replayStore`) and corresponding narrow accessor methods. `Stores` remains as an internal aggregation struct used by `OpenCanonicalDBService` to bundle store initialization; it is no longer retained past the construction site. Affected files: `internal/services/gateway/gateway_db.go`, `internal/services/gateway/gateway_service.go`, `internal/services/g8eo.go`, `internal/cli/serve/gateway.go`, `internal/services/gateway/gateway_service_getters_test.go`, `internal/services/gateway/gateway_service_governance_test.go`, `internal/services/gateway/gateway_service_heartbeat_test.go`, `internal/services/gateway/app_enrollment_service_test.go`, `test/fixtures/gateway_fixture.go`.

* **`HTTPHandlerDependencies` decomposed into per-controller `Deps` structs** — The 19-flat-field God struct is now a composition of per-controller `Deps` structs plus 3 shared infra fields (`Cfg`, `Logger`, `Auth`). The `Stores` bag field is removed entirely — each controller's `Deps` struct carries only the stores it needs. `newHTTPHandler` passes `Deps` structs directly to each `new*Controller` call. All 16 controllers now have `Deps` structs: `PKIControllerDeps`, `AuditControllerDeps`, `DataControllerDeps`, `SignerControllerDeps`, `BootstrapControllerDeps`, `EnrollmentTokenControllerDeps`, `UserControllerDeps`, `SessionControllerDeps`, `AdminControllerDeps`, `OperatorControllerDeps`, `SSEControllerDeps`, `HealthControllerDeps`, `GovernanceControllerDeps`, `MCPControllerDeps`, `PubSubControllerDeps`, `PasskeyControllerDeps`. Affected files: `internal/services/gateway/gateway_http.go`, `internal/services/gateway/gateway_service.go`, `internal/services/gateway/governance_controller_test.go`, `internal/services/gateway/pki_controller_test.go`, `internal/services/gateway/admin_controller_test.go`, `internal/services/gateway/data_controller_test.go`, `internal/services/gateway/operator_controller_test.go`, `internal/services/gateway/gateway_http_test.go`, `internal/services/gateway/gateway_jwt_integration_test.go`, `internal/services/gateway/stores_field_guard_test.go`.

* **Direct accessors on `HTTPHandler` promoted to controllers** — `mcp`, `pubsub`, and `passkey` direct-accessor fields replaced with `MCPController`, `PubSubController`, and `PasskeyController` (thin wrappers exposing the handler methods plus accessors). `auth` field renamed to `authMiddleware` to document its cross-cutting infra role (it exposes only middleware methods, zero HTTP endpoint handlers — no `AuthController` is needed). `responder` kept as a documented exception (cross-cutting infrastructure, not a domain service). `HTTPHandler` now holds 16 controller fields + `authMiddleware` + `responder` + router infra. All router call sites in `gateway_http_router.go` updated (2 MCP, 1 PubSub, 15 Passkey, 7 auth). Affected files: `internal/services/gateway/mcp_controller.go`, `internal/services/gateway/pubsub_controller.go`, `internal/services/gateway/passkey_controller.go`, `internal/services/gateway/gateway_http.go`, `internal/services/gateway/gateway_http_router.go`, `internal/services/gateway/gateway_http_test.go`, `internal/services/gateway/bootstrap_test.go`, `internal/services/gateway/sse_stream_test.go`.

* **Router cache contract documented** — The `router` field on `HTTPHandler` now carries a comment stating the full cache contract: the router is built once at construction by `buildPublicRouter`, never invalidated or rebuilt, and any future runtime reconfiguration would require revisiting the contract (rebuild under mutex or atomic swap). Affected file: `internal/services/gateway/gateway_http.go`.

### Added

* **`MCPController`** — Thin wrapper in `mcp_controller.go` exposing `handleMCP`, `handleA2aCall`, and `MCPGateway()` accessor. Unit tests in `mcp_controller_test.go` (4 tests: wiring, nil-deps, `handleMCP` delegates via 405 guard, `handleA2aCall` delegates via JSON-RPC -32603 "not ready").
* **`PubSubController`** — Thin wrapper in `pubsub_controller.go` exposing `handleWebSocket` and `WebSocketHandler()` accessor. Unit tests in `pubsub_controller_test.go` (4 tests: wiring, nil-deps, `handleWebSocket` delegates via gorilla 400 handshake rejection, `Publish` delegates via 0-delivery with no subscribers).
* **`PasskeyController`** — Thin wrapper in `passkey_controller.go` exposing 12 methods (`registerChallenge`, `registerVerify`, `authenticateChallenge`, `authenticateVerify`, `cliStatus`, `handleApprovalPage`, `handleCLIApprovalStatus`, `handleCLIListSuspended`, `handleApprovalAction`, `handleListSuspendedTransactions`, `listCredentials`, `revokeCredential`) plus `PasskeyHandler()` accessor. Unit tests in `passkey_controller_test.go` (3 tests: wiring, nil-deps, 4 cfg-returning methods delegate via 405 guard, 8 direct methods delegate via 405/401 guards).
* **Lint guard test for `*Stores` field leakage** — `TestStoresFieldNotLeakedPastGatewayDB` in `internal/services/gateway/stores_field_guard_test.go` uses `go/ast` to scan all non-test `.go` files in the gateway package and asserts no production struct outside `gateway_db.go` (`CanonicalDBService`) declares a `*Stores` field. Verified the test catches violations with a temporary struct.
* **Narrow accessor methods on `CanonicalDBService`** — 11 methods (`GetDB`, `GetDocStore`, `GetAppPolicyStore`, `GetSignerStore`, `GetConsensusStore`, `GetStateRootSvc`, `GetReplayStore`, `GetKVStore`, `GetSSEStore`, `GetBlobStore`, `GetAuditStore`), each delegating to `s.stores.<Field>`.
* **Narrow accessor methods on `GatewayModeService`** — 7 methods (`GetDocStore`, `GetConsensusStore`, `GetSignerStore`, `GetAuditStore`, `GetStateRootSvc`, `GetKVStore`, `GetReplayStore`), replacing the removed `GetStores()` bag accessor.
* **`GetEnvProcAdapter()` and `GetSessionValidatorAdapter()` on `GatewayModeService`** — Expose the lazy adapter pointers so `serve/gateway.go` and test fixtures can pass them to `NewGatewayOperatorPubSubService`.

* **`InitHTTPHandler` folded into `NewGatewayModeService`** — `GatewayModeService` now constructs the HTTP handler in the constructor via `gatewayServiceBuilder.build()`, eliminating two-phase construction. The `consensusSvc` and `envProc` parameters on `InitHTTPHandler` are removed. `ConsensusService` is wired post-construction via `SetConsensusService` (a narrow setter for a genuinely late-bound dependency). The `GovernanceController` holds `consensus **consensus.ConsensusService` (pointer-to-pointer): `initHTTPHandler` captures `&ls.consensusSvc` at construction time; `SetConsensusService` mutates `ls.consensusSvc` in place; the controller dereferences at request time. The deprecated zero-arg `InitHTTPHandler()` wrapper has been removed; tests that bypass the constructor call `initHTTPHandler` directly (same package). Affected files: `internal/services/gateway/gateway_service.go`, `internal/services/gateway/governance_controller.go`, `internal/cli/serve/gateway.go`, `internal/services/gateway/gateway_service_test.go`, `internal/services/gateway/gateway_http_test.go`, `test/fixtures/gateway_fixture.go`.

* **`NoopConsensusPolicyStore` and `NoopFieldReader` removed from production outbound code paths** — Outbound mode no longer wires no-op stubs for `ConsensusPolicyStore` and `FieldReader` in `GovernanceDeps`. The constructor defaults in `NewOperatorPubSubService` and the explicit noop assignments in `g8eo.go` are removed. These fields are now nil in outbound mode; the `verifyL2Posture` call site in `l2_consensus.go` nil-checks with fail-closed behavior (matching the old noop semantics: nil policy = no consensus required = proceed). `FieldReader` has no production call sites, so no nil-checks were needed. The noop types are retained as test/chaos-only utilities. Affected files: `internal/services/pubsub/pubsub_commands.go`, `internal/services/g8eo.go`, `internal/services/governance/l2_consensus.go`, `internal/services/mcp/gateway.go`, `internal/services/pubsub/pubsub_commands_test.go`.

### Removed

* **`G8eoService.SetFileService`** — Post-construction setter removed; `fileSvc` is now a constructor arg.
* **`mcp.GatewayService.SetRuntimeDeps` / `runtimeReady` / `getRuntimeDeps`** — Two-phase dependency model collapsed into single-phase construction.
* **`mcp.GatewayService.RuntimeDependencies` struct** — Merged into `Dependencies`.
* **`G8eoService.gatewayStores` field** — Outbound mode uses narrow accessors on `CanonicalDBService` instead.
* **`GatewayModeService.stores` field and `GetStores()` method** — Replaced with 7 individual store fields and narrow accessors.
* **`HTTPHandlerDependencies.Stores` field** — Each controller's `Deps` struct now carries only the stores it needs.
* **`HTTPHandler` direct-accessor fields `pubsub`, `auth`, `passkey`, `mcp`** — Replaced with `pubsubController`, `authMiddleware`, `passkeyController`, `mcpController`.
* **`InitHTTPHandler(consensusSvc, envProc)` parameters** — `InitHTTPHandler` is removed; the handler is built in the constructor. Tests that bypass the constructor call `initHTTPHandler` directly (same package).
* **Noop defaults in `NewOperatorPubSubService`** — Constructor no longer replaces nil `ConsensusPolicyStore` / `FieldReader` with noop stubs.
* **Noop assignments in `g8eo.go` outbound `GovernanceDeps`** — `ConsensusPolicyStore` and `FieldReader` are now nil in outbound mode.
