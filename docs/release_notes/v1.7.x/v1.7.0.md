## [1.7.0] - 2026-08-07

### Overview

SSE routing model refactor. The prior three-way mutually-exclusive routing model (`user_id` / `web_session_id` / `cli_session_id` — pick exactly one) is replaced with a two-dimensional model: `user_id` (ownership, always required) + exactly one session ID (delivery: `web_session_id` or `cli_session_id`). The `user_id`-only fan-out route is removed entirely — approval events are now scoped to the specific CLI session that submitted the transaction, eliminating cross-session leakage. Routing and identity IDs are moved out of URL query strings and into headers / auth context, matching the transport model used by every other gateway controller.

### Changed

* **SSE route requires `user_id` + session** — `SSERoute.validate()` now requires `UserID` (always) plus exactly one of `WebSessionID` / `CLISessionID`. The `user_id`-only route is invalid. Error constants replaced: `ErrGatewaySSERouteUserIDRequired`, `ErrGatewaySSERouteSessionRequired`, `ErrGatewaySSERouteSessionMutuallyExclusive`. Affected files: `internal/services/gateway/sse_event_service.go`, `internal/constants/errors.go`.
* **DB schema: `user_id` NOT NULL** — `sse_events.user_id` is now `TEXT NOT NULL` with a CHECK constraint enforcing exactly one session column. The `user_id` index is no longer partial. Migration purges existing rows (SSE events are transient). Affected files: `internal/services/gateway/db/schema.sql`.
* **SSE handlers build route from context only** — `handleInternalSSEEvents` and `handleInternalSSEStream` no longer read `cli_session_id` or `user_id` from `r.URL.Query()`. A new `buildSSERouteFromContext` helper constructs the route from `ContextKeyUserID` + (`ContextKeyCLISessionID` or `ContextKeyWebSessionID`). The query string carries only `since_id` / `limit`. Affected files: `internal/services/gateway/sse_controller.go`.
* **`authorizeSSERoute` rewritten as ownership-only check** — The `isMTLSAuth`/`isCookieAuth` heuristic and by-value `route.WebSessionID` mutation are deleted. The route arrives fully constructed and validated; the function verifies `ctxUserID` presence, `route.UserID == ctxUserID`, `route.validate()`, then checks CLI session ownership (user + optional operator) or web session ownership (operator binding or cookie-verified). Defense-in-depth: cookie-auth branch verifies `route.WebSessionID` matches `ctxWebSessionID`. Affected files: `internal/services/gateway/sse_controller.go`.
* **`handleInternalSSEPush` requires `user_id` in payload** — The `user_id`-only push branch is deleted. Apps must push to a specific session (web or CLI), not fan out to a user. Authorization branches are two (web session, CLI session), not three. The `sse:user:<user_id>` channel is removed. Affected files: `internal/services/gateway/sse_controller.go`.
* **Operator mTLS stamps session headers into context** — `handleOperatorAuth` now stamps `ContextKeyCLISessionID` and `ContextKeyWebSessionID` into context from `X-G8E-CLI-Session-ID` / `X-G8E-Web-Session-ID` headers, enabling operator mTLS clients to carry full routing context. Affected files: `internal/services/gateway/gateway_auth.go`.
* **CLI consumers use headers, not URL params** — TUI, passkey bootstrap, approval wait CLI, and agent harness drop `?cli_session_id=` / `?user_id=` from SSE URLs and send `X-G8E-CLI-Session-ID` header instead. `user_id` is bound by the mTLS cert. Affected files: `internal/cli/cmd/tui.go`, `internal/cli/auth/passkey_bootstrap.go`, `internal/cli/auth/approval_sse.go`, `internal/tools/agent_harness/client/client.go`, `internal/cli/cmd/approve.go`, `internal/cli/cmd/mcp.go`.

### Added

* **`SubmitterCLISessionID` field on `SuspendedTransaction`** — Tracks the CLI session that submitted a suspended transaction, so `approval.completed` events can be scoped to that specific session. The suspended transaction store schema includes `submitter_cli_session_id TEXT` with an `ALTER TABLE` migration for existing DBs. `mcp.GatewayService.StoreSuspendedTransaction` populates it from `ContextKeyCLISessionID`. Affected files: `internal/models/suspended.go`, `internal/services/storage/suspended_transaction_store.go`, `internal/services/mcp/gateway.go`.
* **`buildSSERouteFromContext` helper** — Extracted from inline route construction in `handleInternalSSEEvents` / `handleInternalSSEStream`. Reads `ContextKeyUserID` + session keys from context, returns a fully constructed `SSERoute`. CLI session takes precedence over web session. Unit-tested in `sse_route_test.go` (6 subtests). Affected files: `internal/services/gateway/sse_controller.go`, `internal/services/gateway/sse_route_test.go`.

### Removed

* **`user_id`-only SSE routing** — The `sse:user:<user_id>` pub/sub channel, the `user_id`-only query branch in `SSEEventsListSince`, the `user_id`-only push branch in `handleInternalSSEPush`, and all `user_id`-only test cases are deleted. `user_id` is an ownership dimension, not a delivery target.
* **Old error constants** — `ErrGatewaySSERouteRequired` and `ErrGatewaySSERouteMutuallyExclusive` are deleted, replaced by the three new constants above.
* **Routing IDs in SSE URLs** — No `cli_session_id=` or `user_id=` query params remain in any CLI or harness SSE URL.

### Security

* **No cross-session approval leakage** — `approval.completed` events are now scoped to the submitter's CLI session, not fanned out to all sessions belonging to the user. A user with multiple active CLI sessions no longer receives approval notifications for transactions they didn't submit.
* **No routing IDs in URLs** — Identity and routing IDs no longer appear in URL query strings, eliminating exposure in access logs, browser history, and referrer headers. This matches the headers→context transport model used by every other gateway controller.
* **Defense-in-depth cookie-auth check** — `authorizeSSERoute` cookie-auth branch now verifies `route.WebSessionID` matches the `ctxWebSessionID` from the authenticated session cookie, preventing a mismatched session ID from passing authorization.

### Tests

* SSE integration test file `gateway_http_sse_test.go` (1423 lines) split into 5 focused files: `sse_test_helpers_test.go`, `sse_push_test.go`, `sse_authorize_test.go`, `sse_events_test.go`, `sse_stream_test.go`. New helpers `seedCLISessionCtx` and `runStreamWithCancel` reduce boilerplate.
* All SSE routes in tests now include `UserID`. Context-stamped session IDs replace URL params. User_id-only test cases deleted (8 tests removed).
* New `buildSSERouteFromContext` unit tests (6 subtests, Tier 1).
* New suspended transaction store round-trip tests for `SubmitterCLISessionID` (3 tests, `-race`).
* New MCP gateway context-population test for `SubmitterCLISessionID` (1 test, `-race`).
