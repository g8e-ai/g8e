## [1.7.3] - 2026-08-14

### Overview

PKI common-name constant centralization and release process documentation cleanup. This release extracts the hardcoded `"g8e Root CA"` root-CA subject common name into a single typed constant, `constants.RootCACommonName`, and replaces every scattered string literal and package-local copy across gateway certificate generation, per-platform OS trust-store installation, and stale-anchor enumeration. The change is internal-only: the on-wire CN value, certificate subjects, trust-store matching behavior, and stale-anchor detection are unchanged. This closes the last hand-rolled copy of the root CA CN and enforces the single-source-of-truth rule from `docs/devs/devs.md` for the PKI hierarchy's root anchor. The release also clarifies the separation of duties in `docs/devs/release_process.md` between the agent (PR prep: inventory, docs, version files, release notes) and the release owner (commit, push, merge, wait for CI, pull main, run `make release`).

### Changed

* **`constants.RootCACommonName` added** — New typed constant in `internal/constants/auth.go` (`RootCACommonName = "g8e Root CA"`) is now the SSOT for the g8e self-signed root CA subject CN. The constant is documented as the canonical reference for CN matching across gateway certificate generation, OS trust-store installation, and stale-anchor enumeration.
* **`gateway_certs.go` uses the centralized constant** — The package-local `rootCommonName` constant in `internal/services/gateway/gateway_certs.go` is removed; `PKIAuthority.generateRootCA` now sets the root CA subject `CommonName` from `constants.RootCACommonName`. The other PKI CN constants (`hubCommonName`, `operatorCommonName`, `gatewayPeerCommonName`) remain package-local in `gateway_certs.go` as they are not referenced outside the gateway certificate generator.
* **Per-platform trust installers use the centralized constant** — `internal/cli/platform/system_trust_darwin.go` and `internal/cli/platform/system_trust_windows.go` now reference `constants.RootCACommonName` for both the `security find-certificate -c` CN filter (Darwin) and the PowerShell `CN=` subject match (Windows), and for the in-process `cert.Subject.CommonName` equality check (Darwin). The previous package-local `g8eRootCommonName` variable is gone.

### Tests

* **Test fixtures use the centralized constant** — Stale-anchor fixtures in `internal/cli/auth/enrollment_coordinator_test.go`, `internal/cli/cmd/gateway_reset_clean_test.go`, and `internal/cli/platform/system_trust_linux_test.go` now construct `StaleAnchor` values and generate test CAs with `constants.RootCACommonName` instead of the literal `"g8e Root CA"` string, keeping the tests coupled to the SSOT and preventing silent drift if the CN ever changes.

### Documentation

* **`docs/devs/release_process.md` separation of duties clarified** — Adds a dedicated "Separation of Duties" section making explicit that the agent does PR prep (inventory, documentation reconciliation, release notes, all version files including `VERSION`, `CHANGELOG.md`, `protocol/python/pyproject.toml`, and `protocol/python/g8e/__init__.py`) and stops without committing, pushing, or running `make release`; the release owner commits, pushes, opens and merges the PR, waits for CI on `main` to pass, pulls `main` locally, and runs `make release` to tag and push. Removes the prior ambiguous step that directed the agent to run `make release` or manually sync the Python files mid-process. Updates the "How to Use This Document" steps, Manual Updates Checklist, Version-Bearing Files table, Verification step 4, Emergency Releases, and Out of Scope sections to match.
