## [1.7.6] - 2026-08-16

### Overview

Documentation reconciliation, Python protocol package alignment, and a CI release-workflow fix for v1.7.6. This release carries no platform code changes; it restructures the architecture, guide, reference, and protocol docs to match the current code surface (gateway construction, MCP/A2A ingress, native tools, L1-L5 pipeline), realigns the Python protocol package headers and component/header constants with the Go single source of truth, and fixes the PyPI publish verification job to install directly from the artifact URL reported by the PyPI JSON API so CDN propagation races no longer cause spurious verification failures.

### Fixed

* **PyPI publish verification installs from the PyPI JSON API artifact URL** — `.github/workflows/release-python-protocol.yml` no longer runs `pip install g8e==${VERSION}` against the pip simple index after polling the JSON API. The job now resolves the canonical wheel URL from `https://pypi.org/pypi/g8e/json` and installs with `pip install --no-cache-dir "g8e @ ${ARTIFACT_URL}"`. The pip simple index is CDN-cached and can lag behind the JSON API, so the previous flow could verify the version is published yet fail to install it. Using the JSON API artifact URL bypasses the stale listing while still resolving dependencies from PyPI.
