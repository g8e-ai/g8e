# MCP Gateway

Last Updated: 2026-05-23

The **MCP Gateway** is the g8e Operator's Model Context Protocol (MCP) server interface. It functions as a universal protocol translator that intercepts standard JSON-RPC tool calls from AI clients, forces them through the g8e governance envelope, and dispatches verified payloads to downstream MCP/A2A servers or local execution handlers.
