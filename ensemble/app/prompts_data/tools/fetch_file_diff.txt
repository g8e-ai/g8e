Retrieve file diffs from the Operator's Sentinel-scrubbed vault, the sole source for diffs this tool returns. Use it to audit file modifications or review exact changes.

<behavior>
1. List: `web_session_id` (optionally with `file_path`) returns diff summaries without content.
2. Detail: `diff_id` returns the full diff.
3. At least one of `diff_id` or `web_session_id` is required.
</behavior>
