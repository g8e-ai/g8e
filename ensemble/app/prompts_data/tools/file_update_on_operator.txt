Find-and-replace edit on a file on the target system through the deployed Operator. Use it for surgical changes; use `file_write_on_operator` to replace a whole file.

<behavior>
- `old_content` MUST match the file exactly, including whitespace. Read the file first and copy the text.
- Fails safely, changing nothing, when `old_content` is not found.
- A backup is made by default.
</behavior>
