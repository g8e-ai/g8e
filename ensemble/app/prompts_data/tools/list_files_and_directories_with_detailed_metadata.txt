List a directory on the target system through the deployed Operator, with stat metadata per entry (name, type, size, permissions, modified time, owner). It is also the canonical existence check: a missing path returns an error.

<behavior>
1. MUST call it before `file_read_on_operator`, `file_write_on_operator`, or file-targeting commands, to confirm the path and exact filename.
2. `max_depth` 0 lists the directory itself, 1 (the default) adds immediate subdirectories.
</behavior>
