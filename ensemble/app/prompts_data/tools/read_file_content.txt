Low-level file reader that bypasses the shell. Prefer `file_read_on_operator`; use this for quick reads of small files or when that tool is unavailable.

<behavior>
- MUST confirm the file exists with `list_files_and_directories_with_detailed_metadata` first.
- Rejects binary files. Truncates at `max_size` (default 100KB, max 1MB) with a warning; MUST NOT use it for large files.
- No line-based reading; use `file_read_on_operator` for `start_line` and `end_line`.
- Follows symlinks. Content is Sentinel-scrubbed.
</behavior>
