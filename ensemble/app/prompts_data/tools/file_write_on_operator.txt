Replace the ENTIRE content of a file on the target system through the deployed Operator. Use it to regenerate or reset a file, or (with `create_if_missing=true`) to write a file that may not exist.

<behavior>
1. MUST call `list_files_and_directories_with_detailed_metadata` first to confirm the file exists, or its parent directory when `create_if_missing=true`.
2. Nothing of the old content is preserved. For small edits use `file_update_on_operator`; for files that must not exist yet use `file_create_on_operator`.
3. A backup is made by default (`create_backup=true`) and the change is tracked in file history.
</behavior>
