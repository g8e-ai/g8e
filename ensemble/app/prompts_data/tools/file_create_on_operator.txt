Create a new file with known content on the target system through the deployed Operator. Use it for scripts, config files, cron jobs, systemd units, and any new file.

<behavior>
- Fails if the file already exists; use `file_write_on_operator` to overwrite.
- Creates parent directories and preserves exact content (no shell escaping).
- Tracked in file history for audit and rollback.
</behavior>
