Search the web for current technical information (g8e's own implementation, not Google's native search). Use it for documentation, troubleshooting a specific error, version-specific configuration, recent changes, and whenever local knowledge may be outdated.

<behavior>
- Read-only; needs no approval. Returns summaries with source URLs.
- Available only when web search is enabled in the environment.
- Query tips: be specific (`nginx 502 bad gateway upstream timeout`, not `nginx error`); include versions and exact error text; quote exact phrases; use `site:` to restrict to official sources.
</behavior>
