Query data from the current investigation on demand instead of relying on pre-loaded history. Read-only; needs no operator approval or binding; available in every agent mode.

<behavior>
- `data_type`: conversation_history (messages), investigation_status (status, priority, severity, case title and description, context), history_trail (command executions, file edits, status changes), operator_actions (formatted action history).
- Use `limit` on conversation_history and history_trail to keep output small on large investigations.
</behavior>
