Enable an AWS capability and run a command under ONE user approval (Zero Standing Privileges). It is the ONLY way to gain AWS access. Use it for any EC2, S3, or other AWS operation.

<behavior>
1. Tell the user "I need [intent] permission to [action]." The user sees one approval card; on approval the IAM policy attaches, `pending_command` executes, and you receive the output.
2. Always include `pending_command` when you know what to run, so no second approval is needed.
3. Permissions are time-limited and revoked automatically after use.
</behavior>

<intents>
- ec2_discovery: list and describe EC2 instances, security groups, VPCs
- ec2_management: start, stop, terminate, modify EC2 resources
- s3_read: list buckets, read objects, get bucket policies
- s3_write: create buckets, upload objects, modify bucket policies
- terraform_state: read and manage Terraform state
- cloudwatch_logs: read CloudWatch logs and metrics
- secrets_read: read AWS Secrets Manager secrets
</intents>
