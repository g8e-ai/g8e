Read a file on the target system through the deployed Operator. This is the default tool for reading file content: configs before changes, logs for debugging, and the text to copy into `file_update_on_operator`.

<behavior>
1. MUST call `list_files_and_directories_with_detailed_metadata` first to confirm the file exists and get the exact name.
2. MUST read a file before updating it so `old_content` matches exactly.
3. For large files, limit output with `start_line`, `end_line`, or `max_lines`; a negative `start_line` reads from the end.
4. Content is Sentinel-scrubbed (placeholders listed in `run_commands_with_operator`) and the read is tracked in file history.
</behavior>
