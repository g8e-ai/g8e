# Public Proof Offline Verification

Download the manifest, catalog, artifacts, and trusted source public key before disconnecting the network. Verify every artifact byte count and SHA-256 against the catalog, require every classification to equal `public_safe`, and require every immutable URL to contain the artifact SHA-256. Recompute the proof root from the exact ordered manifest fields and catalog entries, decode the root hash from hexadecimal, and verify the manifest's Ed25519 signature with the trusted source key. Verify signed feed fixtures by recomputing each record hash, recomputing the batch content hash from the ordered protocol fields, and verifying the Ed25519 signature over the decoded content hash. Any missing artifact, unknown field, hash mismatch, signature failure, traversal path, symlink, or restricted field invalidates the package.
